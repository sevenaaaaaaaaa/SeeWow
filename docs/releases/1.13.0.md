# SeeWow 1.13.0 · 转码清晰度、限速与剩余时间

这一版把离线缓存补完整：Plex / Emby 可以选清晰度转码下载，队列可限速，并显示实时速度与剩余时间。

## 转码清晰度下载

- Plex / Emby 的缓存弹窗现在提供：原始画质、1080p（约 8 Mbps）、720p（约 4 Mbps）、480p（约 1.5 Mbps）。
- Emby / Jellyfin：使用 `Videos/{id}/stream.mp4` 服务端转码，直接落成 MP4 文件。
- Plex：请求 `/video/:/transcode/universal/start.m3u8`，下载 HLS 分片并按顺序拼接为 `.ts` 文件；MPEG-TS 可直接被播放器识别。
- 原始画质仍走直连文件，不经过转码，速度与画质最好。
- 本地、SMB、WebDAV、OpenList 等不能服务端转码的来源只提供原始画质，弹窗里会说明原因。

## HLS 缓存

- 支持 master playlist：按带宽排序挑选最高码率的 variant，再下载它的媒体列表。
- 支持 `#EXT-X-MAP` 初始化分片（fMP4），输出 `.mp4`；普通 TS 分片输出 `.ts`。
- 拒绝加密 HLS（`#EXT-X-KEY` 非 NONE）与直播 HLS（无 `#EXT-X-ENDLIST`），避免留下坏文件。
- 分片逐个下载，进度按实际字节累计；总大小先用「时长 × 目标码率」估算，完成后校正为真实大小。

## 限速

- 离线缓存页新增限速下拉：不限速 / 1 / 2 / 5 / 10 / 20 MB/s。
- 使用按字节配额的节流器，对 HTTP 直链、HLS 分片与本地复制都生效；队列串行，因此限速就是整体带宽上限。
- 限速值持久化到 `downloads.json`，重启后保留。

## 速度与剩余时间

- 每个任务用最近 6 秒的字节增量计算实时速度，显示「x MB/s」。
- 已知总大小时显示「剩余 N 分 N 秒」；HLS 用码率估算值计算，完成后自动校正。
- 暂停、失败、完成时会把速度归零，避免显示过期数字。

## 已知限制

- Plex 转码下载依赖服务器转码器；服务器未启用转码、或不允许该客户端时，会以失败原因提示。
- 暂不支持选择字幕轨 / 音轨，转码下载使用服务器默认设置。
- HLS 加密（AES-128 / SAMPLE-AES）暂不支持。
- 限速只对新建任务或当前任务的下一个数据块立即生效，切换限速不会中断正在传输的请求。
