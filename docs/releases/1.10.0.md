# SeeWow 1.10.0 · 刷新、发现与播放控制

这一版先落地你列出的第一批体验项：下拉刷新、首页更多推荐维度、纪录片 / 短剧支持与管理页标签压缩，并把 AB 循环和画中画从隐藏菜单提到播放控制栏。移动端和电脑端共用同一套实现。

## 刷新

- 首页、媒体库支持下拉刷新，会重新扫描所有已启用片源；扫描失败的来源保留原条目。
- 桌面顶栏新增刷新按钮，扫描中显示进度圈。
- 刷新完成后提示「片库已刷新」，不会清空已有偏好或进度。

## 首页推荐维度

- 保留原有「继续你的故事」和「为你，再多一点发现」。
- 新增「最近加入」：按入库时间倒序的影片。
- 新增「纪录片」：按类型 / 标题里的纪实、纪录、Documentary 归类。
- 新增「短剧」：显式标注短剧 / 微短剧 / 竖屏，或单集时长不超过 20 分钟的剧集；同一部剧只出现一次。

## 纪录片与短剧

- 媒体库新增「全部 / 纪录片 / 短剧」紧凑筛选。
- 选择短剧时进入短剧模式：提示「单集 20 分钟内优先」，并按该分类过滤。
- 分类完全在本地完成，不依赖外部接口；后续可在资料编辑里手动纠正。

## 管理页与筛选

- 筛选下拉、分类标签与「待整理」标签整体缩小（11px 字号、紧凑密度），不再抢占内容空间。
- 搜索框、视图切换与筛选仍集中在一行区域，内容网格下移。

## 播放控制

- 控制栏新增 AB 循环按钮：第一次标记 A，第二次标记 B，第三次清除；已开启时图标高亮。
- 控制栏新增画中画 / 小窗按钮：桌面进入置顶迷你窗，Android 进入系统 PiP，iOS 使用 AVKit PiP；不支持的格式会提示原因。
- 移动端紧凑控制栏保留 AB 与画中画，音量仍可通过手势和设置调整。

## 已经是现有能力的项

- **Emby**：已支持 API Key 接入（与 Jellyfin 共用只读目录与直链播放）。
- **音乐**：已支持 Navidrome / OpenSubsonic 音乐库与本地音频条目。
- **AB 循环与画中画**：底层此前已有，这一版只是把入口放到控制栏，解决「找不到 / 以为没有」。

## 尚未完成（后续批次）

- 超长下拉进入独立「解耦空间」（可定制不同文件夹的第二个片库）。
- 缓存到本地（含 Plex / Emby 等远程片源离线下载与进度管理）。
- 推荐其他在线影视剧资源（需要合规来源与授权口径）。
- 更多资料解析服务（TVDB、豆瓣等第三方适配）。
- 服务器版本（无头服务 + Web 管理端）。

## 验证范围

- 223 项自动化测试通过、2 项原生解码器测试按需跳过；静态分析 0 error / 0 warning。
- 新增 4 项分类与刷新测试：纪录片 / 短剧识别、筛选顺序、刷新只扫启用来源。
- macOS Release 构建与桌面实机启动通过；手机端与电脑端的真实设备联调仍需实测。
- 短剧归类是本地启发式（类型词 + 单集时长），可能把 20 分钟以内的普通剧集误判，后续可在资料编辑中纠正。
