# SeeWow 1.6.0 · 体验预览版

这一版汇总 1.1.0 之后的功能更新：管理私人媒体库、连接 NAS 与媒体服务器、编辑主题皮肤，以及用自己的模型翻译字幕和理解影片。

## 字幕翻译与小映陪看

- 在「设置 → AI 字幕与小映陪看」配置自己的 Chat Completions 兼容 API、模型和密钥；功能默认关闭。
- 翻译已有文字字幕，支持内嵌字幕轨道与外挂 UTF-8 SRT / VTT；播放器同时显示原文与译文。
- 从播放器右上角头像打开女性文字助手「小映」，询问台词、俚语、文化背景、当前情节和场景；回答标记提问时间及所用资料。
- 画面分析需要全局允许，并逐次勾选附图。每次最多发送一张最长边 640px、编码后不超过 512KB 的截图，不连续录屏。
- 会话、翻译缓存和并发请求有上限；关闭功能或应用进入后台会停止任务并释放会话。字幕、截图和问答不写入片库。

## 片库与 Agent

- 统一媒体库筛选、排序、海报 / 列表切换、批量操作、收藏、待看、已看和继续观看。
- 可编辑类型偏好，使用片库内推荐，保存搜索或推荐结果为片单。
- Agent 支持本地规则与自配模型两种模式，显示规划步骤、结果、失败和取消；模型通过受限工具搜索片库、推荐、体检、刷新来源和生成片单。
- 详情页手动搜索、预览并确认 TMDB 匹配；支持中文资料与本地 / SMB / WebDAV 的 NFO 旁车读取。

## 来源接入

- 增加 Plex、群晖 File Station、Navidrome / OpenSubsonic、OpenList / Alist API 接入，以及连接编辑、失败恢复和播放前动态直链解析。
- 飞牛 NAS 通过 SMB / WebDAV 接入；Jellyfin / Emby 使用 API Key，Plex 使用服务器 Token。
- 夸克、百度、UC、OneDrive、Google Drive、MEGA、123、115 提供服务入口，首轮通过用户已配置的 OpenList / Alist 网关连接；尚未提供这些网盘的原生授权。
- Navidrome 提供音乐库目录与播放。媒体服务器当前读取目录和原文件流，不回写服务端观看状态，也不协商转码。

## 主题与移动端

- 曜黑、素白、流光玻璃主题，皮肤工作室可编辑颜色、字体、圆角、密度与材质。
- 支持社区皮肤 JSON / Markdown 导入导出；design.md 可本地生成或使用自配模型生成皮肤，预览确认后应用。
- iOS / iPadOS 增加钥匙串凭据、Files 文件夹授权、局域网访问说明，以及手机播放控制、安全区域和横竖屏适配。

## 升级与验证范围

- 沿用已有片库、来源和皮肤偏好；升级前建议备份 application-support 目录内的 `SeeWow/`。新写入的片库不再保存认证头，凭据从应用凭据存储恢复。
- AI 功能需要自行配置 API，并可能产生服务费用。密钥不写入配置 JSON；macOS / iOS 使用钥匙串。字幕翻译不包含无字幕语音识别或图片字幕 OCR；陪看为文字交互。
- 94 项自动化测试通过，静态分析无 error / warning；macOS 原生播放器通过本机测试 API 验证字幕导入、翻译、文字陪看与单帧请求。
- macOS、iOS ARM64、Android Release 构建完成；Android 已核对版本、联网权限、APK 签名与 16KB ZIP 对齐。iOS / Android 尚未完成真机运行验证，Windows / Linux 本轮未构建。
- 真实模型回答质量、真实 NAS / 网盘账号兼容性仍需实际连接验证。没有全网影片搜索、网盘原生 OAuth、语音陪看或持续视频理解。
