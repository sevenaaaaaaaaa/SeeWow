# SeeWow 1.12.0 · 离线缓存

这一版实现「本地缓存 / 离线下载（含 Plex）」的主链路：选择存放位置 → 加入下载队列 → 缓存在本地 → 优先离线播放，并在详情页标记来源。

## 缓存入口

- 影片 / 剧集详情页新增「缓存到本地」；已缓存时变成「离线播放」。
- 弹窗里确认画质与存放位置，点「开始缓存」即加入队列。
- 设置 → 离线缓存：查看全部任务、总占用、存放位置，可暂停、继续、重试、删除。

## 画质与存放位置

- 当前版本对直连片源提供「原始画质（直连文件）」：不转码、不损失画质，下载的就是片源文件。
- 「数据节省（转码）」显示为不可用并说明原因：Plex / Emby 的转码流是 HLS，当前不把 HLS 切片拼成离线文件。
- 桌面默认存到 `~/Movies/SeeWow`，也可在离线缓存页选择任意文件夹；手机存到应用文档目录下的 `SeeWow/`。
- 文件命名使用片名 + 短 id，避免不同来源同名覆盖。

## 下载队列

- 任务顺序执行，状态：等待中 / 缓存中 / 已暂停 / 已离线 / 失败。
- HTTP 直链支持 Range 续传：暂停后再继续，从 `.part` 已下载的位置接着下；服务器不支持 Range 时自动从头开始。
- 本地文件（含 SMB 挂载、已下载文件）走分块复制，同样显示进度。
- 失败会保留原因（网络、HTTP 状态、写入失败、HLS 不支持），可一键重试。
- 队列持久化到 `downloads.json`；App 退出后未完成任务标记为暂停，重开可继续。

## 离线播放与来源标记

- 播放时优先使用已缓存的本地文件，即使 Plex / Emby / WebDAV 暂时离线也能播放。
- 详情页按钮显示「已离线」，播放按钮直接走本地文件。
- 离线缓存页显示来源名称、画质、大小与状态；删除缓存只删本地文件，不动片源。
- Plex 使用 `library/parts` 直连文件、Emby 使用 `Videos/{id}/stream?static=true`，都带原有令牌请求头；令牌不会写进 `downloads.json`。

## 已知限制

- HLS / 转码流（含 Plex 转码、直播）暂不支持离线缓存。
- 暂不支持「只缓存前 N 分钟」或按清晰度转码；后续可接 Plex / Emby 的转码下载接口。
- 移动端后台下载受系统限制，锁屏后可能暂停；重新打开 App 会继续。
- 暂不显示剩余时间 / 实时速度，只有进度百分比与已下载大小。
