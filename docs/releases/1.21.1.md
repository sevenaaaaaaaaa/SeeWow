# 1.21.1 修复版（26）

> 构建：1.21.1+26 · iOS ARM64 未签名预览包 · 上一版是 1.21.0 (25)

## 0. 这一版为什么存在

1.21.0 的 iOS 包在 **11-20 18:17** 就打完了。之后 22:00–00:40 之间做的九件修复与适配，**全都发生在这个包之后**：所以装 1.21.0 那个 IPA，看到的一定还是旧界面、旧行为——不是修复没做，是包里没有。这一版把这些内容真正打进二进制，并把版本号抬到 1.21.1 (26)，好让「装上的是不是新的」这件事能被版本号直接回答，不必靠感觉。

## 1. 修了什么

| # | 问题（用户原话） | 根因 | 修法 |
| --- | --- | --- | --- |
| 1 | iOS 本地已下载的 Plex 资源识别不出来，被判定为已删除 | `downloads.json` 存的是容器**绝对路径**，iOS 升级/重装后 `Application/<UUID>/` 会变，旧路径全部失效 | 新增 `downloads/sandbox_path.dart`：按容器内相对路径重挂到当前容器；重挂不上再在下载目录里按**唯一**文件名兜底；还找不到才报「文件已丢失」 |
| 2 | 底部 tab 错位，整排看起来偏左 | 座位是等宽定尺格子，但格子内容按 `topStart` 收缩摆放，每格少了半个格宽 | `_Seat` 用 `SizedBox.expand` 撑满 + 双向居中；五个座位图标与文字中心误差 < 0.6pt |
| 3 | 媒体库上面筛选条件占用过大 | 五个下拉平铺成三行，分类 chip 再独占一行，合计约 278pt | 压成一条 34pt 横滚筛选带 + 一行条目计数，实测约 49pt；五个下拉收进「筛选」底部面板，保存片单移到顶栏 |

## 2. 接了什么

| # | 能力 | 边界 |
| --- | --- | --- |
| 4 | 「在线源」入口：搜片 → 线路 → 选集 → 直接开播 | 只接苹果 CMS 直连采集站（14 个，去重后），YouTube 式分享页走下面第 8 条 |
| 5 | TVBox 配置导入：粘一条配置地址，自动挑出可直连的采集站与直播源 | jar / js / py 爬虫**不加载**——Dart 跑不了 Java 类与 TVBox spider API，界面上直接写明跳过了几个 |
| 6 | 短剧：按「短剧 / 微短剧 / 竖屏」分类名匹配，再按 `t=<type_id>` 翻页 | 分类 id 每站不同，所以按名称匹配，不写死 id |
| 7 | 来源批量管理：全部更新 / 批量添加 / 批量管理 | 一条失败只记进报告，不停整批；「断开」只解除连接，不删任何文件 |
