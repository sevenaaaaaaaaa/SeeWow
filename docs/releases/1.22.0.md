# SeeWow 1.22.0

> 日期：2026-11-25（北京） · tag：`v1.22.0` · build：35
> 这一版把「交互层」从播放器里拆出来，并给它配了数据：胶片轨、trickplay 缓存、章节轨。

## 1. 这一版是什么

两件事合成一个版：

- **暗房调色板**（`4ed102d`，视觉迭代 M1）：首页与片库去掉冷蓝雾与面板感，回到黑底 + 封面撑色；顶栏噪声收敛。
- **交互层 M2 第一步**（`e8ce44b`）：把进度条从「时间刻度」改成「第二条内容轨」。

第二条才是这一版的重点。四家参考（Infuse / IINA / Plex / Apple TV）的进度条都只表示时间；
本机手里有「秒 → 帧图」的索引，所以能画琥珀短刻度（精彩帧）、灰色长线（章节）、
虚线（译配断点），并在拖动时把该秒的画面浮出来。

## 4. 已知限制（这一版没有改进它们）

- **trickplay 的取帧路径没有上过机**：`MediaKitTrickplaySource` 里「让 mpv 自己缩到 160 px」
  与 `screenshot()` 的组合只在命令行 mpv 上验证过（42–67 ms/帧）。app 内若拿不到，
  缓存会落到「原尺寸帧」或把该条目标 `failed`，播放本身不受影响，但拖动预览没有图。
  **这是这一版最该先看的一条。**
- 章节走 mpv 的 `chapter-list` 属性，同样没有上机验证；ffprobe 那条只在桌面上有意义（iOS 没有这个二进制）。
- 译配断点仍是空轨：`DubbingController` 现在流式生成、不落盘，没有可画的段落索引。
- iOS 仍未真机验证（画中画在模拟器上不可用）。
- 亮度不持久；浮窗位置不持久。
