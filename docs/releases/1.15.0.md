# SeeWow 1.15.0 · 用代理绕开移动端两个硬差异

这一版不改片源协议，而是用两个代理解决系统限制：电脑做局域网媒体代理，手机做画中画回环代理。

## 移动端 SMB → 电脑媒体库（局域网）

- 手机「片源 → 电脑媒体库（局域网）」：搜索电脑或手填地址，输入电脑「手机遥控电脑」里的 6 位配对码即可连接。
- 电脑端把当前片库通过 HTTP 暴露给手机：`/bridge/library` 返回条目、`/bridge/stream` 提供带 Range 的视频流、`/bridge/poster` 提供海报。
- SMB 仍由电脑挂载（macOS NetFS / Windows net use / Linux gio），手机只播放 HTTP，不再需要 SMB 客户端。
- Plex / Emby / WebDAV 也由电脑解析：电脑加上原始认证头后转发，手机拿到的是无认证头的流，因此 iOS 画中画也能用。
- 连接流程只需要一次配对；手机端令牌存进系统凭据库，片源信息只保存地址。

## iOS 画中画 → 手机内回环代理

- 当播放地址带认证头时，iOS 的 AVKit 不接受自定义请求头，原本无法 PiP。
- 现在播放器在手机内启动一个只监听 127.0.0.1 的临时代理，AVKit 播放 `http://127.0.0.1:<port>/s/<随机 token>`，代理再带上认证头请求上游，并原样转发 Range、状态码与内容长度。
- 代理 token 随机生成、只在本机回环可访问，PiP 停止时清空；不支持匿名访问其他地址。
- 普通无认证头的流仍直接播放，不经过代理。

## 安全边界

- 局域网代理的流地址带 32 字节随机 `bridgeKey`，只对当前片库中真实存在的条目有效，不是开放代理，也不能请求任意 URL。
- `/bridge/library` 需要配对令牌；`bridgeKey` 与配对码一起显示在电脑端，重装 / 重置后自动更换。
- 电脑重启后配对令牌清空，手机重新扫描需要再配对一次；已开始的播放流仍凭 `bridgeKey` 继续。
- 回环代理只在手机本机监听，不对外网开放。

## 使用步骤

1. 电脑：设置 → 手机遥控电脑，打开开关，记下地址与配对码。
2. 手机：片源 → 电脑媒体库（局域网），搜索电脑或手填地址，输入配对码。
3. 手机扫描完成后即可浏览电脑片库；SMB / Plex / Emby 条目都能直接播放。
4. 需要画中画时，点播放控制栏的画中画按钮；带认证头的流会自动走回环代理。

## 已知限制

- 电脑必须开机、与手机同一 Wi-Fi，且「手机遥控电脑」开关保持开启；电脑休眠会中断。
- 所有桥接流量都经过电脑，带宽与转码压力在电脑侧；大码率片源建议同一局域网 / 5GHz Wi-Fi。
- 桥接只代理直连文件与渐进式 HTTP，不代理 HLS 播放列表（Plex 转码流请在手机端直接播放或先缓存）。
- iOS 回环代理与 PiP 仍需真机验证；App 被系统强制退出后代理失效。
