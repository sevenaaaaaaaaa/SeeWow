# SeeWow 1.18.0 · 让版本号不再骗人

这一版**没有新功能**，只修一件事：界面上的版本号一直是错的，你没法判断手上这个包到底是哪一次构建。

## 问题

- 「设置 → 关于 SeeWow」的副标题被硬编码成 `1.6.0 · Cinema, made personal.`，从 1.6 之后无论发多少版，这里永远显示 1.6.0。
- 字幕下载的 User-Agent 同样写死 `SeeWow v1.6.0`，服务端看到的也一直是旧版本。
- 结果：重装、重打包、换平台，界面上看不出任何差别。真实版本只存在于 `Info.plist`，普通用户不会去看。

## 改了什么

- 新增 `lib/app/build_info.dart`：版本号与构建戳由构建参数注入（`--dart-define=SEEWOW_VERSION / SEEWOW_BUILD_STAMP`）。
- 关于页显示真实的构建身份：`1.18.0 · 66c2697 · 2026-11-15T21:58`（版本 · 提交 · 构建时间）。
- 用 `flutter run` 直接跑的开发构建会显示 `1.18.0 (dev)`，不会伪装成某个正式版本。
- 字幕 User-Agent 跟随版本号，不再写死。
- `pubspec.yaml`：`1.17.0+20` → `1.18.0+21`。

## 工程验证

- `flutter test --concurrency=1` → **307 通过 / 2 跳过 / 0 失败**，与 1.17.0 基线一致。
- `flutter analyze lib` → **0 error**（401 条历史 info，与改动前同源，未新增）。
- macOS Release 构建通过（103.2 MB），`App.framework` 内可检出构建戳 `66c2697`。
- iOS 真机 ARM64 Release 构建通过（46.9 MB），同样含构建戳。
- 安装包完整性：ZIP 测试通过；IPA 内 `Payload/SeeWow.app` 版本 1.18.0 (21)，`lipo` 记 arm64。

## 本次没有做的事（避免误解）

- **没有功能变更**：界面、播放、片库、元数据行为与 1.17.0 完全相同。
- 只构建了 **macOS 与 iOS** 两个包；Windows / Linux / Android 本次未出包。
- 1.17.0 之后仓库里的改动集中在 Rust 内核线（`apps/seewow-rs`：mpv 封装、续播/字幕/按键/偏好等 M3 任务），**不在这一版应用里**，它还不是能替换主应用的内核。
- iOS 包未签名、未在真机安装验证；macOS 包未公证（首次打开需右键 → 打开）。

## 升级注意

- 覆盖安装即可，片库、偏好、进度都在本机数据目录，不受影响。
- 之前若在 Finder 里注册过多份 SeeWow（构建目录里那份、系统占位副本），双击可能打开旧包；本机已清理为只保留 `/Applications/SeeWow.app`。若你换机器后遇到版本号还是旧的，先确认打开的是哪一份。
