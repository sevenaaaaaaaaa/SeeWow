# 1.21.0 · 视觉与入口一轮

> 版本 1.21.0 (25) · 2026-11-20 · 主题：液态玻璃规范、入口与标识

这是一版**外观与交互**的发布，不改片源、扫描、播放内核，也不改任何数据格式；升级不需要迁移。

## 1. 液态玻璃按规范重做

旧的玻璃只有「模糊 + 描边 + 高光带」三层，看起来像半透明卡片。现在固定五层：背景模糊 → 色调体 → 外高光边 → 内阴影边 → 接触投影。内外描边之间留 1.4 px 的缝隙，这条缝就是材料厚度。

- 嵌套面板按同心圆角算：底栏 28、选中块内缩 6，得 22，不再是两个各自拍的数字。
- 深色与浅色两种材质各用自己的描边与投影（白描边画在白玻璃上就是假玻璃）。
- 系统开启「降低透明度」时不再挂背景模糊，直接给不透明面；有测试守着这条。
- 页面开合改成 0.958 缩放 + 12 px 下沉 + 淡入。

**边界**：真折射（采样背景做位移）与玻璃融合动画受 Flutter 能力限制，这一版没有做，界面上也没有暗示做了。

## 2. 入口

- 底部第五个座位**记住上次进入的分区**，图标与名称跟着变；已站在该分区上时再点才开抽屉，抽屉是玻璃分组面板（浏览 / 管理）。
- **卡片一次点按直接起播**：桌面悬停浮出玻璃播放钮，手机常驻（手机没有 hover）。
- 键盘：⌘1…⌘5 切换分区；⌘K 调色板新增「设置」分组，8 条对话框型设置点一条直达。
- 空态不再只有一句话：媒体库「清除筛选」、片源页「选择接入方式」、离线缓存「去片库挑一部」、Agent「先让 Agent 检查片库」。
- 手机顶栏只保留标题、搜索与两个图标；刷新与空间切换移入抽屉，不再挤到溢出。
- 设置页 AI 分组每行都有状态胶囊（已接入 / 未配置），读的是对话框写入的同一批存储，关掉对话框即刷新。
- 直播：筛选与收藏星命中区 44，触屏设备常驻显示收藏星。短剧卡片可聚焦、可键盘打开。小映面板支持抓手下拉收起与 Esc。
- **Esc 规则成文**：最内层打开的界面拥有 Esc。详情、离线缓存、陪看面板各自用 `EscapeToPop` 包住自己，不做全局绑定。

## 3. 标识

新图标是「玻璃播放碎片 + 顶点光 + 四角星」：轮廓不等半径（168 / 150 / 214），材质带棱镜色散、湿边高光与内阴影倒角，光从顶点穿出画框继续走。旧的「白方块 + 黑三角」每个播放器都有，且和 AI 没有关系。

同一份矢量源码（`lib/design/brand_mark.dart`）生成应用内标记、启动页与三端全部图标尺寸；iOS 图标是无 alpha 的 RGB PNG。
