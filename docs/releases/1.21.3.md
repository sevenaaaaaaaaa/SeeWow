# 1.21.3 内置源可播版（28）

> 构建：1.21.3+28 · macOS Universal 预览包 · 上一版 1.21.2 (27)
> 起因：装好 1.21.2 之后，界面上看不到内置播放源。

## 0. 三件真事

1.21.2 把源包放进了包里，但**入口在第 5 席「更多」弹层里**：底部栏第 5 个 tab 当时默认写着「短剧」，要点两次才弹到「在线源」。首页 665 行里没有一处提到在线源，第 4 席叫「片源」却只放本地 / NAS / 网盘 / 直播订阅——所以「装了却看不到」是界面事实，不是错觉。

第二件：包里的 14 个站点，2026-11-23 实测只有 5 个能连（7 个 8 秒超时、1 个 403、1 个 404）。就算找到入口，搜片也大概率空手。

第三件：下载侧从来没有这个功能。GitHub 最新 Release 是 v1.20.1（11-19）；`dist` 里的 Android 1.20.1 / 1.21.0 包，`libapp.so` 按 UTF-16 搜「在线源」「采集站」各 0 处——开功能那个提交 `7eb39be` 是 11-21 00:51，比这两个包都晚。Windows / Linux 停在 1.17.0。

## 1. 这一版改了什么

| 项 | 内容 |
| --- | --- |
| 源包 | v1 的 14 个站全量重测，剔掉 9 个死站，换成本版 20 个；每个都用「庆余年」「狂飙」「流浪地球」实测返回过 m3u8/mp4 直链 |
| 入口 | 底部第 5 席默认就是「在线源」，一点直达；首页首屏加「在线采集站」直达条；「片源」页第一个卡片也是它 |
| 迁移 | 装过 v1 的机器本地清单早已存在，按旧规则永远不会换包。本版按 v1 的站点 id 精确剔除旧内置站，再铺新版；`custom-*`（用户自己加的）和从 TVBox 配置导入的站一条不动 |
| 版本号 | 1.21.3 (28)。1.21.2 已经发出去了，同一版本号下不能有两个不同二进制 |
| 顺手修的 | 「在线源」页头部在 390pt 窄屏下溢出 33px（`ONLINE SOURCES` 那行不肯缩）。入口一露出来这个就在手机宽度上撞出来了，改成可省略的单行 |

- `flutter test test/builtin_sources_test.dart`：8 条全过——源包存在且声明在 pubspec、解析出的站点数与代码种子一致且去重键唯一、v1 死站不得回流、代码种子与 JSON 是同一份清单、asset bundle 里真的打进了 v2 包、首次启动铺满、**装过 v1 的机器会被迁移且用户的站点不被吃**、已是本版的机器重复启动不叠加也不重置开关。
- `flutter test test/online_entry_test.dart`：从手机宽度（390×844）打开应用，断言底部第 5 席标签是「在线源」而不是「短剧」，点一下直接进到可搜索的页面，标题下写着 20 个站点。这条就是「装了要看得见」的回归。

- 站点实测（2026-11-23）：22 个候选全部用两个以上片名验过，进包的 20 个都有可播直链；被排除的候选里 `wolongzyw.com` 返回 HTML、`tyyszy.com` 回「暂不支持搜索」、`154.219.117.232:9981` 有列表但 `vod_play_url` 里没有 m3u8/mp4。

## 4. 分发规则：带源与不带源

**本地/自用的包带源，上 GitHub 的包不带。** 这不是习惯，是三条构建路径：

| 去处 | 带内置源 | 怎么出包 |
| --- | --- | --- |
| 本机 `/Applications`、`dist/` 里的预览包 | 带（20 个站） | `flutter build macos --release --dart-define=SEEWOW_VERSION=…` |
| iOS IPA、iCloud `SeeWow/` 那一份 | 带（20 个站） | `tool/build_ios_ipa.sh --dart-define=…`，再拷进 iCloud |
| GitHub Release（公开分发） | **不带** | `tool/build_macos_public.sh`：把 `builtin_sources.json` 挪走，加 `--dart-define=SEEWOW_NO_BUILTIN_SOURCES=true`，代码种子也不生效，脚本会校验产物里没有源包才打包 |

不带源的那份，用户在「在线源 → 站点」里自己填采集站接口，或粘一条 TVBox 配置导入；界面文案会写「本版不随包内置站点」，不会假装有 20 个站在里面。

公开包用下一个 build number（28 → 29），两个二进制不会同号。

| 项 | 值 |
| --- | --- |
| 本地包 | `dist/SeeWow-macos-1.21.3-preview.zip` · 1.21.3 (28) · macOS Universal · ad-hoc、未公证 |
| iOS 包 | `dist/SeeWow-iOS-1.21.3-arm64-unsigned.ipa` · 1.21.3 (28) · 未签名，需自备证书重签 |
| 公开包（可上 GitHub） | `dist/SeeWow-macos-1.21.3-public-nosources.zip` · 1.21.3 (29) · 不含任何站点 |
| 上传状态 | 都还没上传，等你点头 |
