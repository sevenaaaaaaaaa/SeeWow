# SeeWow 1.7.2 · 移动端对齐版

1.7.1 修好了本地目录、飞牛 / NAS 的 SMB 凭据和 Plex 登录，但手机端还有两处平台差异：Plex 登录页不会自动打开，Android 13+ 选完目录也读不到媒体。这一版把手机端补到和桌面同一套能力，桌面安装包也同步更新。

## Plex 账号登录（全平台）

- iPhone / iPad / Android 也会在申请验证码后自动打开 https://plex.tv/link，验证码可复制；登录成功后自动列出服务器、优先局域网连接，并填入地址与 Token。
- 桌面端改用同一套系统浏览器打开逻辑，不再依赖 `open` 命令。
- 手动「地址 + Token」方式继续保留。

## Android 本地文件夹

- 选择目录前会申请「音乐和音频」「照片和视频」权限，授权后按真实路径递归扫描；拒绝授权时会回到选择器，不会静默失败。
- Android 13+ 使用 `READ_MEDIA_VIDEO` / `READ_MEDIA_IMAGES` / `READ_MEDIA_AUDIO`，Android 12 及以下使用 `READ_EXTERNAL_STORAGE`。
- 在 Android 模拟器上完整验证：申请权限 → 系统目录选择器选 Movies → App 显示来源 `Movies`、路径 `/storage/emulated/0/Movies`、扫描成功并识别 1 个条目。

## iPhone / iPad 本地文件夹

- 继续使用系统「文件」选择器，保存安全书签，重启后自动恢复访问授权。
- iOS 模拟器已验证应用启动与片源流程可正常显示；未连接真实 iPhone / iPad 做安装验证。

## 桌面

- macOS 安装包同步重新构建（Universal），包含同一套 Plex 登录与本地目录容错修复。
- 桌面 SMB 仍使用系统 NetFS，凭据在钥匙串不可用时回落到 0600 的 `secrets.json`；日志与错误提示沿用 1.7.1。

## 平台差异（明确限制）

- **手机端不支持 SMB 直连**：iOS 没有公开的 SMB 客户端 API，Android 需要额外引入 SMB 库。飞牛、群晖在手机上请启用 WebDAV（或通过 OpenList）接入；桌面端继续支持 SMB。
- Android 分区存储下，目录内非媒体文件（NFO、海报图片）可能读不到；媒体文件本身可正常扫描与播放。
- iOS 受 Files 授权范围限制，移动或撤销目录后需要重新选择。
