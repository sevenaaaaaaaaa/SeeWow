# SeeWow 1.7.0 · 体验预览版

这一版把片库从「能看」推进到「看得懂、放得安心」：资料可以按地区和多语言补全，可以用自己的资料服务与图像模型补齐封面，直播订阅支持更多来源，播放器加入手势、音量隐私、AB 循环、精彩帧、小窗与语音译配。

## 地区资料与多语言

- TMDB 搜索支持语言、电影发行地区和分页；保留原始标题、真实译名、地区别名、人员、评分票数与图片候选，同一影片的多地区结果去重。
- 日本、韩国、香港、台湾、俄罗斯、西班牙、阿拉伯语和藏文优先展示；港版与台版资料独立保存，缺失语言明确留空，不用机器翻译冒充官方译名。
- NFO 旁车保留语言、地区、人员、不同尺度的评分与相对图片路径；本机支持 UTF-8 与带 BOM 的 UTF-16，未确认资料随扫描更新，人工确认的资料保留。
- 本机批量补译最多 20 个条目，连接用户自备的本机 Chat Completions 模型，生成缺失标题、简介与角色／职务称谓的翻译预览，确认后才写入；逐字段区分资料源与机译，保留原名与人员姓名，原资料变化时提示译文可能过期。
- 新增 Noto Serif Tibetan 与 Noto Sans Arabic 字体，离线显示藏文与阿拉伯语标题。

## 自定义资料服务与 AI 封面

- 「设置 → 自定义刮削 API」最多配置 20 个 GET JSON 适配，按电影、分集、其他视频和自定义分类选择；搜索参数、详情路径与字段映射均可在配置中声明，预览确认后应用到当前条目。
- 请求有界：不跟随重定向、响应不超过 4 MiB、30 秒超时；密钥单独存放在本机凭据存储，不写入 `library.json`；默认只允许 HTTPS，本机回环或显式开启局域网例外。
- 只读取元数据，不拼接可执行表达式，不接触媒体路径与片源凭据。
- 「AI 生成封面」使用用户自备的本机或远程 Images API，为缺少封面的条目生成原创配图：可编辑描述、主动生成、预览后保存本机；已有封面需明确选择替换，并保留模型、时间与 AI 配图标记。
- 字幕管理与检索独立于 AI：轨道选择、本地字幕导入、同名旁车发现；OpenSubtitles 使用用户自配 Key 与可选账号，按语言与发行版本检索、下载、加载并管理本机缓存。

## 直播订阅

- 支持 M3U / M3U8、常见 TXT、纯数据 JSON，以及 TVBox 多仓与 `lives` 配置；逐层预览频道，确认后才导入。
- 订阅读取只当数据：限制条目数量、不跟随跨域重定向、不执行播放器选项、插件或本地路径展开。
- 直播页保留分组、收藏、最近观看、XMLTV 节目单与订阅刷新。
- 新增 Telegram 本地媒体来源：选择已下载到设备的媒体目录，复用本地扫描与播放；该来源不进入 AI 模型目录，也不开启 AI 字幕与陪看。原生账号、频道与聊天文件夹直连尚未实现。

## 放映与播放

- 放映入场：光盘旋入／SeeWow 聚光片头／直接放映，约 2.1 秒可跳过，尊重系统「减少动态效果」；先准备影片，片头结束再播放，不截掉正片开头。
- 手势：横滑与两侧长按快进快退并显示时间预览；长按 2 倍速；多指按住锁定触控但继续播放，桌面 L / Esc 或长按解锁。
- 音量策略：新文件默认静音，双击解除；外放上限 30%、耳机上限 50%，当天记住选择；切换音频输出先静音再切换。
- 外放隐私保护：依据显式标记或用户自行运行的本机回环分类器判断，触发后本次播放保持静音；分类器不主动联网，不上传画面或音频。
- AB 循环要求 B 点晚于 A 点至少 0.5 秒，直播不启用；精彩帧保存原始画面、时间点与备注，仅存本机，可图库查看、缩放、移除，并从该时间点回到本片。
- 音频电平按实际 PCM 样本计算 RMS，原片按需独立采样，译音复用返回的 PCM；不读取麦克风，不支持采样时明确显示不可用。
- 语音译配为前台点播实验功能：用户自配语音适配服务、目标语言并声明保留音色；约 6 秒分段、最多两段缓冲、1× 译音播放，需逐次确认音频发送与费用。
- 小窗与后台：桌面置顶迷你窗口与完整控制栏全屏；Android 8+ 系统 PiP 与用户开启的媒体前台服务；iOS 后台原声音频与 AVKit PiP（受媒体格式与认证方式限制）。

## 升级与验证范围

- 沿用已有片库、来源、进度与皮肤偏好；升级前建议备份 application-support 目录内的 `SeeWow/`。新写入的片库不保存认证头，凭据从应用凭据存储恢复。
- 自动化测试 202 项通过、2 项原生解码器测试按需跳过；静态分析 0 error、0 warning（409 条 info 级提示）。
- macOS、iOS ARM64、Android Release 构建完成；桌面人工检查因系统屏幕捕捉接口错误未完成，移动端真机插拔、蓝牙音频与后台播放尚未验证。
- 资料服务、图像与语音模型、OpenSubtitles 均需用户自备凭据并可能产生费用；密钥不写入配置 JSON，macOS / iOS 使用钥匙串。
- 尚未实现：Telegram 原生账号直连、跨平台统一的系统级画中画、Windows / Linux 安装包、无字幕语音识别与图片字幕 OCR。
