# 1.21.2 内置源包版（27）

> 构建：1.21.2+27 · iOS ARM64 未签名预览包 + macOS Universal 预览包 · 上一版 1.21.1 (26)

## 0. 这一版只做一件事

把播放源**放进包里**，装完就能搜片，不用先粘配置、不用先导入。

从 1.21.2 起，源清单是一个真实文件：`assets/sources/builtin_sources.json`。它在 IPA 里能被 `unzip` 看到，在应用里是首次启动的铺底数据；改它就能换包，不必改 Dart 代码。代码里原来的 `seedOnlineSites` 退成兜底——源包文件读不到（旧包、测试环境、插件异常）才用它，启动不会卡在这一步。

## 1. 内置了什么

| 项 | 内容 |
| --- | --- |
| 站点 | 14 个苹果 CMS 直连采集站（去重后；金蝉与 789 同址只留一条） |
| 接口形态 | `?ac=videolist&wd=` 查询，返回 JSON 或 XML，播放地址直出 m3u8 / mp4 |
| 不包含 | jar / js / py 爬虫站——它们要 TVBox 的插件运行时，本应用不加载 |
| 直播 | 不在内置清单里：在「在线源 → 站点」粘一条 TVBox 配置地址，导入后进「直播」页 |
| 首次启动 | 没有本地清单时按源包铺满 14 个站点并落盘；第二次启动读本地清单，不重复叠加 |

## 2. 界面上的变化

「在线源 → 站点」的副标题现在直说：**内置 14 个直连采集站**，并说明粘 TVBox 配置可再导入、直播源进「直播」页。以前这行只说「采集站用纯 HTTP 接口」，看不出源是随包带的。

## 4. 验证

- `flutter test`：新增 `builtin_sources_test.dart` 5 条——源包文件存在且声明在 pubspec、解析出 14 个站点且去重键唯一、与代码种子是同一份清单、**asset bundle 里真的打进了源包**、首次启动铺满 14 个且二次启动不叠加。
- 解包核对：`Payload/SeeWow.app/Frameworks/App.framework/flutter_assets/assets/sources/builtin_sources.json` 存在，内容含 14 个站点；`CFBundleShortVersionString` = 1.21.2、`CFBundleVersion` = 27、平台 iPhoneOS、arm64。
- macOS 本机安装验收：1.21.2 覆盖掉 `/Applications` 里的 1.18.0 后启动，首次启动写出 `~/Library/Application Support/com.seewow.seewow/online_sources.json`，内容正好 14 个站点且全部启用——内置源包在真实应用里跑通了，不只是单测里通过。
- 未做：iOS 真机安装验收；内置站点在移动网络下的实际可播率（各站可达性随网络变化，1.21.1 那次实测 14 个里 4 个能连通、其余本机网络不可达）。

## 5. 升级

数据格式没变。已经运行过旧版的设备，本地 `online_sources.json` 已存在，本版**不会**覆盖用户的清单；想换成内置源包，进「站点」删除后重启，或在「站点」里点「全部启用」再逐条确认。iOS 已下载资源的路径修复（1.21.1）在本版同样生效。
