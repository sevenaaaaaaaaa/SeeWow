# SeeWow 1.22.1（草案，未发版）

> 日期：2026-11-26（北京） · tag：无 · build：仍为 35（版本号未 bump）
> 这一版没有功能变化：对前端做了一次「雪豹式」清理——不加新功能，只修 lint、对齐设计令牌、迁移弃用 API。

## 1. 这一版是什么

一次只做打磨的版本。三条线：

- **静态清理 430 处**（`dart fix`）：流程控制大括号 341、字符串拼接改插值 61、多余导入 11，以及集合字面量、初始化形参等零散项。
- **手修真问题**：下载弹层的 `RadioListTile` 弃用 API（`groupValue` / `onChanged`）迁移到 `RadioGroup` 祖先——这是 SDK 自 3.32 起就标记弃用的旧写法；片源页复制验证码的异步回主线程守卫改 `context.mounted`；11 处 `dart fix` 啃不动的复杂大括号；`tool/` 与探针测试的 `print` 属诊断输出本意，加文件级豁免。
- **设计令牌对齐 20 处**：直播页 15、批量刮削弹窗 3、设置页状态药丸 1、评价卡 1。这些都是「随皮肤的 panel 面上直接叠白」——`tokens.dart` 的注释明令禁止的写法，素白皮肤下半透明白会隐形（0.08 白叠在亮底上是 1.05:1，等于消失）。文字与图标改走 `WowColors.fade()`，填充、描边、分隔线改走 `WowColors.wash()`。graphite 深色皮肤下逐像素等价，所以这一版对深色用户没有任何视觉变化；素白皮肤下这些部件第一次真正可见。

## 3. 刻意不做（雪豹的克制）

- **material_ui 迁移**。SDK 提示 `package:flutter/material.dart` 已弃用（3.47 后提示改用 `material_ui`）。实际尝试 `dart fix` 全量迁移：`material_ui` 不是 drop-in 替代（无 `SizedBox` 等基础部件），104 个文件直接产生 9934 个错误，**已完整回滚**。这属于未来专项迁移，104 条提示保持可见比压掉更诚实。
- **场景色不换令牌**。海报渐晕（`0xC8101314` 系）、影院入场动画色、直播红点、固定深色弹窗（`0xFF0C0F15`）里的白与彩色叠加是场景专属色，换成随皮肤的令牌反而破坏视觉；`video_look` 渲染滤镜、`skin.dart` 调色板、`brand_mark` 品牌矢量里的字面色同理保留。

## 4. iOS 功能对齐（同一轮完成）

审计 1.21.7–1.22.0 新能力在 iOS 的真实状态（详见 [对齐说明](../parity.md) 2026-11-26 复核）：胶片轨 / trickplay / 章节轨 / 频谱 / 手势 / 小映浮窗 / 画风都是同一套 Dart，无平台门槛；章节在 iOS 无 ffprobe 时由 mpv 内嵌信息兜底。**唯一真缺口是自动解说**——TTS 只接了桌面三端，iOS 入口直接消失。

本轮补齐：`AppDelegate.swift` 新增 `IOSVoiceBridge`（`seewow/voice` 通道），用 AVSpeechSynthesizer 离线渲染成 16 位单声道 PCM WAV（AVAudioConverter 转换、120 秒看门狗、产物不足 128 字节按失败丢弃），与桌面 `say + afconvert` 交给播放器的产物等价；Dart 侧 `SpeechSynthesizer` 增加 `ios` 后端分支与平台覆盖注入点。无系统语音时如实不可用，不回落任何在线服务。

新增 5 项通道协议测试（探测 / 不可用 / 委托与产物校验 / 失败抛错 / 空文本短路），`flutter test` 总量 613 通过 / 2 跳过。**AVSpeechSynthesizer 渲染路径只有编译与协议验证，真机音色与时长校准未验**；IPA 由 `tool/build_ios_ipa.sh` 重出，见 [iOS 构建说明](../ios-build.md)。
