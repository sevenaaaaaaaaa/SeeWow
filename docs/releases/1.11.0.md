# SeeWow 1.11.0 · 解耦空间

这一版实现你清单里的「超长下拉进入解耦空间」：模一样的界面、不需要单独配置，但可以拥有完全不同的文件夹与片库。

## 入口

- 手机 / 触控板：在首页继续下拉超过约 180 像素，直接进入解耦空间；松手后会有「已进入解耦空间」提示。
- 桌面：顶栏「主空间 / 解耦空间」小标签点一下即可切换；解耦空间顶部还有「返回主空间」。
- 两边的界面、导航、播放器完全一致，不额外学习一套操作。

## 独立但不重复配置

- 解耦空间是一个独立的片库实例：有自己的文件夹（片源）、条目、收藏、观看进度、片单、口味与 Agent 上下文。
- 在解耦空间里「连接片源 / 添加本地文件夹」，只会加到解耦空间，不会污染主空间；反过来也一样。
- 主空间与解耦空间各自下拉刷新、各自扫描、互不覆盖；资料编辑与播放记录也分别保存。
- 数据位置：主空间 `SeeWow/`，解耦空间 `SeeWow/space2/`（macOS 在 `~/Library/Application Support/com.seewow.seewow/` 下）。

## 适合怎么用

- 主空间放日常电影 / 剧集；解耦空间放短剧、纪录片、家庭视频或另一块硬盘。
- 想临时清空注意力时，进入解耦空间只看那一类内容；回到主空间，原来的推荐与进度原样保留。
- 手机遥控电脑时，手机看到的是电脑当前所在空间，选片会打开当前空间的条目。

## 已知限制

- 第一次进入解耦空间是空的，需要重新连接文件夹——这是「独立片库」的设计，不是漏配。
- 暂不提供主空间与解耦空间之间的条目迁移；后续可加「复制到另一个空间」。
- 分类、短剧等启发式规则在两个空间各自独立生效。
