# 1.21.5 五端同 tag 发版（31）

> 构建：1.21.5+31 · 上一版 1.21.4 (30) 只有 macOS 公开包

## 2. tag 被移动过一次——如实记录

`v1.21.5` 这个公开 tag 名被重写过一次。时间线（UTC；本地 +08）：

| 时间 | 事件 | 证据 |
| --- | --- | --- |
| 12:10:09 | 第一次 annotated tag `v1.21.5` 建立：tag 对象 `a297b9c7`，指向 `88dbce2` | 本机 `git cat-file -p a297b9c7`（该对象现为 dangling，远端已不存在） |
| 12:10:14 | run `45390928295` 开跑，sha `88dbce2` | `gh run view 45390928295` |
| ~12:21:29 | 五个平台全绿；`release` job 在第一步「打包 + 校验和」失败 | 失败日志：`ls: Broken pipe` → `##[error]Process completed with exit code 1` |
| 12:24:56 | 修复提交 `309ec74`（1 个文件，3 增 1 删） | `git show --stat 309ec74` |
| 12:26:53 | 删掉旧 tag，在新提交上重建：tag 对象 `701bf43` → `309ec74` | `git cat-file -p v1.21.5` |
| 12:27:01 | run `45393606265` 开跑，六 job 全绿 | `gh run view 45393606265` |
| 12:39:16 / 12:39:21 | 五个资产上传 / Release 发布 | `gh release view v1.21.5` |

失败原因值得写下来，因为它是 CI 打自己：打包脚本第一行是 `ls -R artifacts | head -60`，而脚本开着 `set -euo pipefail`。`head` 读够 60 行就关管道，`ls` 收到 SIGPIPE 非零退出，整步立刻失败；下一步 `softprops/action-gh-release` 因此没跑到，**Release 没有创建，一个资产也没有**。修法是把这行换成 `find artifacts -maxdepth 2 -type d | sort`（输出本来就不大，不需要截断）。

**事实与代价分开说：**

- 事实：公开 tag `v1.21.5` 曾经指向 `88dbce2`，现在指向 `309ec74`。远端旧 tag 已删，本地只剩 dangling tag 对象 `a297b9c7` 作证据。
- 事实：重写发生在 Release 创建之前。那一刻 Release 不存在、资产为零，所以不存在「有人下到旧包」。
- 事实：两次构建的应用代码是同一棵树——`309ec74` 只改 workflow。即便有人拿到第一次的产物，内容也等价。
- 代价：公开 tag 历史确实被改写了一次。`v1.21.5` 不再指向它最初指的位置，任何以 tag 为锚的引用（外部脚本、镜像、别人写的笔记）拿到的都是后一个提交。这条记在这里，不用「反正没人下载」带过。

**版本号规则（从现在起算）：** 1.21.5 已公开，同一个号下面不能出现第二个二进制。真要撤，只有一条路——删 Release、删 tag，然后以 **1.21.6** 重发；不能把 1.21.5 覆盖一遍。

## 3. 「公开包不带内置源」目前的确切含义

这句话现在只对了一半，写清楚：

- **做到的部分**：公开构建传 `--dart-define=SEEWOW_NO_BUILTIN_SOURCES=true`（`88dbce2`）。`online_source_store.dart` 里 `_noBuiltinSourcesDefault = bool.fromEnvironment('SEEWOW_NO_BUILTIN_SOURCES')` 为真时，既不铺内置包、也不铺代码里的种子站。装好打开，站点列表是空的——行为和 README 的承诺一致。
- **没做到的部分**：文件还在包里。从 Release 下载的 `SeeWow-Android-1.21.5.apk`（`05dd8009…`）用 `unzip -l` 仍然列出 `assets/flutter_assets/assets/sources/builtin_sources.json`，3718 字节，sha256 `bdcb9e55…`——与本机预览包里那份**字节完全相同**，就是那 20 个站。不用启动 App，解压就能读。

所以准确说法是：**公开包运行时不启用内置源；没有把它们从包里剔掉。** 想拿站点的人不需要用这个 App，解 3.7 KB 的 JSON 就够。这是已知缺口（见 §5），修法是把该 asset 从公开构建的 Flutter assets 里排除——改构建矩阵或加条件化 assets 声明。本版没做。

## 5. 这一版没做的事（避免误读）

1. **公开包里的站点清单文件还在**（§3）：分发规则目前只做到「运行时不加载」。
2. **缓存加速倍数没测**：只验证了 libmpv 属性名与清理规则，没测真机拖动 / 回看快多少。
3. **iOS 不在 Release**：未签名包装不上，只在本机自签用（`docs/ios-build.md`）。
4. **Windows / Linux 没有实机安装验证**：本机是 macOS，只能证明 CI 构建与打包通过。
5. **macOS 包体积异常**：1.21.3 是 42,505,967 字节、1.21.4 是 42,605,558，这版 124,150,561，约三倍。原因未查明，下版前要查清，否则下载成本一直背着。
6. **Android 是第一个带「在线源」入口的公开包**，但里面没有任何内置站：第一次打开要自己填采集站接口，或导一条 TVBox 配置。
7. **上一版留下的错账没有回改**：v1.21.4 Release 里的 `SHA256SUMS.txt` 头部把构建号写成 `(31)`（实际 `1.21.4+30`，31 是这一版），其中预览包那行的哈希也已与本地文件不符。公开资产那一行的哈希是对的。已发布的资产不改写，错处记在 [版本汇总 §3](../release-index.md)；从这一版起校验值由 CI 现算（`sha256sum *`，没有手写头部）。

```sh

  --jq '[.jobs[]|"\(.name):\(.conclusion)"]'

  --jq '"draft=\(.isDraft) pre=\(.isPrerelease)", (.assets[]|"\(.name) \(.size)")'

mkdir -p /tmp/v1215 && gh release download v1.21.5 \
  -R sevenaaaaaaaaa/SeeWow --pattern 'SeeWow-Android-1.21.5.apk' --dir /tmp/v1215

  assets/flutter_assets/assets/sources/builtin_sources.json | shasum -a 256   # bdcb9e55…
```
