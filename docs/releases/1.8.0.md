# SeeWow 1.8.0 · 手机遥控电脑

手机和电脑在同一 Wi-Fi 下时，手机上的 SeeWow 可以直接控制电脑上的播放：播放 / 暂停、拖动进度、前后 10 秒、音量。不需要登录账号，不做公网穿透。

## 怎么用

1. 电脑端打开「设置 → 手机遥控电脑」，开启开关；记下 6 位配对码和电脑地址（形如 `192.168.1.10:47834`）。
2. 手机端打开「设置 → 手机遥控电脑」，点「搜索电脑」自动发现，或手动填写电脑地址与端口。
3. 输入配对码，连接后即可遥控当前正在播放的影片。

## 能力

- 播放 / 暂停、进度条拖动、后退 / 前进 10 秒、音量 ±5。
- 手机端每秒同步一次播放状态，显示片名、时间与音量。
- 电脑端显示已配对设备数量、局域网地址与配对码；可一键更换配对码并让旧令牌失效。
- 手机端既支持局域网自动发现，也支持手动输入地址；发现被路由器限制时仍可手动连接。

## 安全边界

- 只在局域网监听，不提供公网地址、不依赖云端；关闭开关立即停止监听。
- 配对使用 6 位数字码，验证码连续错误 5 次会被限制 30 秒；配对成功后使用随机令牌，令牌只保存在内存中，重启或换码后需重新配对。
- 遥控接口只暴露当前播放器状态与播放控制，不开放片库浏览、文件读取或任意命令；请求体限制 8 KiB，响应不回传媒体路径或凭据。
- 默认端口 HTTP `47834` / UDP 发现 `47833`；端口被占用时 HTTP 会尝试相邻端口并在界面显示实际地址。

## 平台说明

- 电脑端（macOS / Windows / Linux）作为被控端；手机端（iPhone / iPad / Android）作为遥控端。
- macOS 首次开启时系统会询问是否允许 SeeWow 接受传入连接，请选择允许；否则手机无法连接。
- iOS 首次使用会触发「本地网络」权限询问；Android 需要与电脑在同一 Wi-Fi，部分路由器的 AP 隔离会阻止发现与连接。
- 手机端 SMB 仍未接入，与本功能无关；飞牛 / 群晖在手机上继续使用 WebDAV。

## 验证范围

- 218 项自动化测试通过、2 项原生解码器测试按需跳过；静态分析 0 error / 0 warning。
- 新增 7 项遥控测试：配对失败 / 成功、令牌校验、播放 / 暂停、进度夹取、音量、无播放时拒绝、UDP 发现、设置持久化。
- 桌面遥控服务与真实手机端到端联调需要你实测；本轮用本机客户端脚本验证了真实进程的配对与状态接口。
- 已知限制：一次只遥控当前打开的播放器；暂不支持在手机上浏览片库选片；不支持跨网段或公网。
