# SeeWow 1.20.0 · 接入与入口版

这一版只解决两件被用户直接点出来的事：**接什么都要自己拼地址**，和**找什么都要在一条长列表里翻**。播放内核、片库结构、元数据回退链都没有改动。

## 为什么先改这里

反馈来自真机截图，四句话：

1. 「各类 API 只支持一两个，尤其不支持开源」；
2. 「AI 模型不预设常用平台，让他自己输入 baseurl 很扯」；
3. 「Plex 链接后音乐不会呈现在库中」；
4. 「本地已缓存的作品管理不方便，设置页的入口也不合理」。

对应的根因分别是：模型地址只能手填完整路径（填域名就 404 或返回网页）、Plex 扫描器硬编码 `movie` / `show`、媒体库没有缓存维度、设置页把导航/功能/配置/清理混成一列。

## 改了什么

### 1. AI 模型：平台预设 + 地址补全 + 测试连接

- 弹窗新增「常用平台」：OpenAI、DeepSeek、硅基流动 SiliconFlow、OpenRouter、通义千问（百炼）、智谱 GLM、Moonshot Kimi、火山方舟豆包、本机 Ollama、本机 LM Studio；选中即填完整地址与推荐模型，模型名仍可改。
- 地址可只填域名或 `主机:端口`：`api.deepseek.com` → `https://api.deepseek.com/v1/chat/completions`；`http://localhost:11434` → 自动补全并保持 HTTP；带版本前缀的厂商（如 `open.bigmodel.cn/api/paas/v4`）会保留自己的路径前缀。
- 新增「测试连接」：保存前发一条 8 token 的最小请求，成功显示 `连接成功 · 模型可用`，失败给出可读原因。
- 模型请求的报错重写：非 200 且返回网页时提示「网页而不是 JSON，请确认以 `/chat/completions` 结尾」；200 但返回 HTML、空响应、非 Chat Completions JSON、模型没按要求输出规划，各有独立文案，不再把 `Unexpected character` 抛给用户。
- 同一套补全与网页识别也用在「AI 字幕与小映陪看」和「本机翻译」地址上。

### 2. 语音译配：通用 JSON 适配层

- 「语音译配 API · 实验性」新增接入方式：内置 SeeWow 分段协议，或「通用 JSON 适配」。
- 通用适配由用户写请求模板（占位符 `{{model}}`、`{{target_language}}`、`{{audio_base64}}`、`{{audio_format}}`、`{{source_at_ms}}`、`{{source_duration_ms}}`，值按 JSON 转义），再用点路径从响应里取音频（如 `data.audio_base64`）、可选文字与可选音色字段。
- 认证头可配：名称默认 `Authorization`，可选择是否加 `Bearer` 前缀；局域网 HTTP 仍需显式勾选。
- 约束与原协议一致：Base64 PCM 16-bit WAV、≤2 MiB、译音与原片段时长差 ≤15%、模板 ≤20 KB、渲染后请求体 ≤6 MiB；响应里填了音色字段就要求为 `true`，否则不替换原声。
- 旧配置无需迁移：没有 `protocol` 字段时按内置协议读取；切换接入方式不会清掉已写的模板。

### 3. Plex 音乐：artist 资料库按曲目导入

- 连接 Plex 时的资料库列表不再只列电影/剧集，音乐资料库显示为「音乐 · N 位艺术家」。
- 扫描对音乐库按 `type=10` 分页拉曲目，入库为音频条目：艺人、专辑、年份、时长、曲风、Plex 专辑封面、比特率、`viewOffset` 断点；播放走原文件流，`X-Plex-Token` 随请求头带上。
- 音乐列表行改为「艺人 · 专辑 · 来源」并在右侧显示时长，不再显示「年份 · 来源 · 未看完」和待看按钮。
- **升级注意**：已经连过的 Plex 来源保存的是旧的资料库 key 集合。要导入音乐，去「片源 → 编辑连接 → 重新选择资料库」勾上音乐库再保存；当初保存为「全部」的来源，直接下拉刷新即可。

### 4. 媒体库：已缓存筛选

- 与「待整理」并排新增 `已缓存 · N`：一键只看本机可离线播放的作品；缓存为空时提示先选中影片点「缓存选中」。
- 底层一次遍历任务表得出可离线集合，避免每次重建对每个条目做一次文件存在检查。

### 5. 设置页重排

- 原来一长条平铺改成 6 组 + 关于：**外观与氛围 / AI 与智能 / 播放 / 字幕 / 存储 / 内容与来源**。
- 「AI 模型」一行显示当前模型与域名，或「未接入 · 使用本地规则模式」；「离线缓存」显示已离线与进行中数量。
- 删除设置页顶部重复的「我的片单 / 直播 / 音乐库」按钮：这三个入口只在底部「更多」面板出现一次。

### 6. Rust 后端：播放接线（源码，无安装包）

- `apps/seewow-rs` 的 M3 播放模块入库：起播点与片头片尾判断、字幕轨菜单、节流落盘、跨剧集的精彩帧隔离。
- 修复测试里的两处过期引用（`WatchState` 应从 `seewow-library` 导入、续播期望值没算 3 秒回退），`cargo test -p seewow-app` 全绿。

## 数据与升级

- `library.json` 结构未变，覆盖安装即可；Plex 音乐条目是新增条目，不影响已有电影/剧集与进度。
- `agent.json` 只是把地址存成补全后的完整地址；已有配置原样可用，重新保存一次即可享受补全。
- 语音译配配置新增 `protocol` / `bodyTemplate` / `audioPath` / `textPath` / `voicePath` / `authHeader` / `authBearer`，缺省按内置协议，回退到 1.19.0 会忽略这些新字段。
- 设置项换了分组，位置变了但功能没少；「AI 模型」仍在「AI 与智能」第一项。

## 本版未修（写在明面上）

- **通用语音适配只支持 JSON + Base64 PCM WAV**：multipart 上传、二进制响应、流式返回都不支持；也不内置任何厂商预设（没有可核验的端点与密钥，不写猜测配置）。
- **在线字幕仍只有 OpenSubtitles**：新增字幕源要先定协议与授权模型，本版没动。
- **Plex 音乐按曲目平铺**：不建专辑/艺人层级，不读歌词，不支持服务端转码；Jellyfin / Emby 的音乐资料库同样未接。
- **移动端真机矩阵**（iOS / Android 各一台）仍未补：本地目录权限、Plex 改选音乐库、后台缓存。
- 桌面系统级画中画、下载内核重做、HLS / 直播离线缓存仍未做（与 1.19.0 相同）。
