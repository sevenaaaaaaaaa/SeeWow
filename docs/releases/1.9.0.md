# SeeWow 1.9.0 · 手机浏览片库并投到电脑

1.8.0 让手机能遥控电脑上的播放；这一版再往前一步：手机上可以直接浏览电脑的片库、搜索片名，点一下就在电脑上打开播放。

## 新增

- 遥控连接成功后，控制页新增「浏览电脑片库」。
- 手机端可以按片名搜索，列表显示标题、年份、电影 / 剧集 / 视频类型和时长。
- 点选条目后，电脑立即进入播放页并开始加载该影片；手机会自动回到遥控页，继续显示播放状态。
- 电脑端无需额外操作，沿用「设置 → 手机遥控电脑」的开关与配对码。

## 数据与安全

- 片库接口只返回条目 id、标题、年份、类型与时长；**不返回文件路径、片源地址、凭据或海报文件**。
- 打开影片只接受当前电脑片库中真实存在的 id，找不到会返回明确错误。
- 沿用局域网限制、6 位配对码、内存令牌、5 次/30 秒错误限速与 8 KiB 请求上限。
- 仍然不开放删除、编辑、扫描或任意命令；手机只能选择已有条目并控制当前播放器。

## 已知限制

- 片库列表暂不显示海报缩略图（后续可加图片代理）。
- 一次只能控制电脑上当前打开的播放器；在手机上切换影片会替换电脑当前播放。
- 手机端 SMB 未接入，与本功能无关；飞牛 / 群晖在手机上继续使用 WebDAV。
- 需要手机与电脑在同一 Wi-Fi；路由器 AP 隔离会阻止发现和连接。

## 验证范围

- 219 项自动化测试通过、2 项原生解码器测试按需跳过；静态分析 0 error / 0 warning。
- 遥控测试扩展到 8 项：片库列表、搜索过滤、数量上限、打开存在的条目、打开不存在的条目、未配对拒绝，以及原有的配对 / 令牌 / 播放控制 / 发现 / 持久化测试。
- 本机真实桌面进程验证：片库返回 16 个条目，搜索 “Dune” 命中 2 条，打开后电脑进入播放页并显示片名；演示片源是占位文件，实际解码会提示播放失败，属例库限制。
- 手机端真机与电脑的端到端联调仍需实机验证。
