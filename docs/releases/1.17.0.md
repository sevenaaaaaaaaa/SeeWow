# SeeWow 1.17.0 · 多源元数据与自动解说

这一版做两件事：**匹配资料不再只有 TMDB 一条路**，以及**让影片自己开口讲一段**。前者解决"TMDB 没收录 / 没有 key / 动画资料不全"，后者把 1.16 的 AI 陪看骨架接到了播放器上，能生成、能朗读、能导出。

## 多源元数据：一条链，不是一个接口

- 匹配弹窗的数据源改为四项：**TMDB、TVmaze、Bangumi、已连接的 Jellyfin / Emby 服务器**，默认「自动回退（多源合并）」。
- 自动回退会按顺序问下去：前一个没有结果或报错，就换下一个；某个源额度用完、断网或未配置，不会让整个弹窗空掉。搜索框下方会写明**每个源问到了几条、哪个失败了、为什么**。
- 类型不对的源会被跳过，而不是先请求再报错：TVmaze 没有电影数据，选电影时它不参与；手动选中它也会先提示，不会发一个注定失败的请求。
- 详情预览会补缺口：主源没给简介、评分或演职人员时，用同一部作品在其他目录里的候选合并进来。**主源回答过的字段永远不被覆盖**。
- 每条资料都记下**逐字段来源**（`fieldSources`）：标题来自 TMDB、简介来自 Bangumi、评分来自 TVmaze 一目了然。详情页用中文小标签列出，空字段不会被硬塞一个来源。

## Jellyfin / Emby 原生元数据

- 已连接的 Jellyfin / Emby 服务器本身就是一份目录：服务器整理的简介、类型、年份、社区评分、演职人员、服务器海报与背景图，都能直接拿来用。
- 只读：读取条目与图片地址，不回写服务器、不修改服务器资料。
- 服务器条目的 ID 是 GUID，而本机资料用整数 ID；匹配时把 GUID 存在 `externalIds` 里，取详情时按 GUID 回查，不会因为 ID 类型不同而匹配错片。

## 自动解说

- 播放器「更多」菜单新增**自动解说**：用你在 AI 陪看里已经配置好的模型写解说词，用系统自带语音朗读。
- 两种范围：**片头 30 秒**（3 到 4 句钩子，落在前 30 秒）与**全片**（默认 8 段，均匀铺开，最后一段在结束前 2 分钟）。风格可选影评人、科普、剧情回顾、轻松吐槽。
- 播放时**压低原声而不是静音**：解说说完音量自动恢复。系统语音不可用、某段合成失败，都只提示一次，不会把影片留在一片安静里。
- 脚本解析很克制：模型输出外面包了说明文字、代码围栏，或多给了负时间、超长句、贴在一起的两段，都会被丢弃或合并，不会喂给播放器。
- **可导出**：所有段落合成成一条 16 位 PCM WAV 音轨，按时间点插入静默，附一份 JSON 时间点清单。导出走系统的"保存文件"对话框，你可以挑位置。
- 数据边界：只发送影片标题、年份、类型、简介与片长给模型；**不上传画面、不上传声音**；`aiAllowed` 为假的来源（如 Telegram 本地媒体）不提供入口。

## 工程与验证

- 新增 `lib/metadata/metadata_registry.dart`：数据源注册表、回退链、逐字段来源、缺口合并。以后加一个目录只实现 `MetadataSource` 一个接口，UI 不用再改。
- 新增 `lib/metadata/emby_metadata_client.dart`、`lib/playback/commentary_export.dart`。
- 测试：新增元数据注册表 13 项、Jellyfin/Emby 协议 4 项、解说脚本 9 项、解说音轨导出 6 项、TVmaze/Bangumi 协议 8 项，合计 40 项。
- 验证：`flutter analyze lib test` → 0 error / 0 warning（427 条历史 info，与改动前同源）；`flutter test --concurrency=1` → **307 通过 / 2 跳过 / 0 失败**。

## 已知限制

- **Bangumi 客户端按官方 v0 协议实现，但本轮没有连真实服务验证**：构建机到 `api.bgm.tv` 的 TCP 连接超时。请求路径、请求体、User-Agent、限速（约 1.1 秒一次）都有协议测试覆盖，真实返回仍要你在能访问的网络上试一次。
- **导出的音轨不是混音**：只有人声，没有背景音乐、没有闪避包络；段落之间的静默是纯静音。采样率不一致（不同 TTS 引擎混用）时直接报错，不做重采样。
- **系统语音取决于平台**：macOS 用 `say` + `afconvert`，Windows 用 SAPI，Linux 用 `espeak-ng`。三者音色不同，Linux 的中文质量明显弱于 macOS。
- 解说脚本依赖你配置的模型质量；模型不按 JSON 输出时会被解析器整段丢弃，并提示重试。
- **1.16 计划里的桌面画中画收尾（第 5 项）本轮仍未做**，仍然是桌面置顶小窗与手机系统 PiP。
