# SeeWow 1.16.0 · 手势、专题、短剧与免版权片库

这一版改的是"怎么找片、怎么看"：刷新手势换掉，首页从 3 个货架变成自动专题，短剧有了独立入口和连播，Plex 可以只导入你想要的资料库，新装用户第一部片不用配置任何东西。

## 手势：摇一摇刷新，超长下拉进解耦空间

- 下拉刷新取消。**手机摇一摇、电脑晃窗口**才是刷新，向下拖超过约 180 像素进入解耦空间。
- 只在"没有点击、没有播放"时响应：播放中、以及刚点过界面 3 秒内都不会触发，避免看电影时误刷新。
- 电脑没有加速度计，所以用窗口晃动的方向反转来判定，不使用按键。

## 首页：自动专题

- 原来只有「最近加入 / 纪录片 / 短剧」三排，现在按片库自动生成专题：剧集连看、高分精选、值得一看、4K、HDR、一小时以内、一小时出头、长片、类型、年代、国家、导演或演员作品、高分冷门。
- 每个专题至少 4 部才出现，且不同维度交错排列，不会连着五排都是类型。
- 同一部剧只占一张卡，不会一集一张。

## 短剧模式

- 侧栏新增「短剧」入口：竖屏 9:16 卡片、按剧聚合、显示集数与单集时长。
- **自动连播**：一集播完自动接下一集，不用再点。整部播完才停。
- 判定沿用现有规则：标题或类型含短剧/竖屏，或单集 20 分钟以内的剧集。

## Plex：只导入你要的资料库

- 用 Plex 账号登录并选完服务器后，会列出该服务器的电影/剧集资料库（带条目数），勾选后只导入勾选的。
- 选择会保存到这条连接里，之后在「编辑连接」可以改；老连接默认保持"全部导入"，行为不变。

## 免版权示例片库

- 首页空态新增「载入免版权示例片库」：6 部可直接播放的影片，不登录、不配置、不需要本地文件。
- 全部是 CC BY 或公共领域：Blender 开放电影（大雄兔、大象之梦、辛特尔）、诺斯费拉图（1922）、女友礼拜五（1940）。
- 每部的简介里都写明许可与来源，播放地址全部实测可用。

## 离线缓存：批量缓存

- 片库多选后新增「缓存选中」，可以一次把整季或整个货架加入缓存队列，已缓存的自动跳过。
- 断点续传、限速、缓存目录设置在 1.12 起已有，这一版只是把入口做到能一次选一批。
