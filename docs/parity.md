# 移动端与电脑端对齐说明

SeeWow 的界面与业务逻辑来自同一套 Flutter 代码，功能默认双端共享。真正需要区分的是「系统能力」而不是「产品功能」。本文列出当前对齐状态、桌面 / 移动独有能力，以及仍然存在的差异。

## 完全共享（同一套代码）

| 能力 | 桌面 | 移动 | 说明 |
| --- | --- | --- | --- |
| 首页推荐 / 继续观看 / 最近加入 / 纪录片 / 短剧 | 是 | 是 | 同一套推荐与本地分类 |
| 下拉刷新 / 桌面刷新按钮 | 是 | 是 | 桌面用按钮，移动下拉 |
| 媒体库 / 搜索 / 筛选 / 排序 / 批量选择 | 是 | 是 | 同一套 LibraryView |
| 详情页 / 收藏 / 待看 / 观看进度 / 片单 | 是 | 是 | 同一套数据模型 |
| 解耦空间 | 是 | 是 | 桌面顶栏标签，移动长下拉或图标 |
| 影院 Agent | 是 | 是 | 同一套对话与整理能力 |
| 直播 / IPTV | 是 | 是 | 移动从「更多」或设置进入 |
| 音乐库 | 是 | 是 | 移动从「更多」或设置进入 |
| 播放器 / AB 循环 / 画中画入口 | 是 | 是 | 桌面迷你窗；移动系统 PiP |
| 手机遥控电脑 | 主机 | 客户端 | 设计上手机控制电脑 |
| 离线缓存 / 队列 / 续传 / 限速 / 剩余时间 | 是 | 是 | 同一套 DownloadManager |
| Plex / Emby 转码清晰度下载 | 是 | 是 | 服务端转码，与客户端平台无关 |
| 本地文件夹 / WebDAV / OpenList / Emby / Jellyfin / Plex / 群晖 / Navidrome | 是 | 是 | 除 SMB 外 |
| 刮削 / NFO / 自定义 API / 字幕 / 语音译配 | 是 | 是 | 需要网络与对应服务 |

## 电脑端独有

- **SMB 挂载**：macOS 用 NetFSMountURLSync、Windows 用 `net use`、Linux 用 gio；移动端没有公开的 SMB 文件系统 API。
- **遥控主机**：桌面作为被控端，提供配对码与局域网服务；手机只做客户端。
- **迷你窗**：桌面播放器可缩成置顶小窗；移动端使用系统画中画。
- **缓存目录选择 / 打开文件夹**：移动端没有用户可写的任意目录，缓存固定在应用文档目录。
- **侧栏导航与多栏布局**：窄屏切换为底部导航 + 「更多」面板。

## 移动端独有

- **Android 媒体权限 / SAF 目录选择**：读取系统媒体库与文件夹。
- **iOS 本地网络权限提示**：首次连接局域网片源 / 遥控时由系统弹窗。
- **系统画中画**：Android PiP、iOS AVKit PiP。
- **锁屏 / 后台播放**：由移动系统调度，桌面无此限制。

## 已知差异（无法完全对齐）

- **移动端 SMB**：系统不提供 SMB 客户端 API；继续使用 WebDAV / OpenList / File Station。
- **iOS 画中画与认证头**：AVKit 不接受自定义请求头，Plex / Emby 带令牌的网络流无法直接 PiP；先缓存到本机后可画中画，桌面迷你窗不受影响。
- **移动后台下载**：锁屏后系统可能暂停任务，重新打开 App 会继续；桌面可一直下载。
- **手机作为主机**：当前设计不开放；如需「手机播放、电脑遥控」，后续可加。

## 本轮对齐修复（1.14.0）

- 移动端离线缓存页不再显示「选择存放位置 / 打开文件夹」这两个桌面专属操作，改为说明手机缓存目录；Android 也不再调用不支持的目录选择器。
- 移动端底部「更多」改为面板，直接进入「我的片单 / 直播 / 音乐库 / 设置」，与桌面侧栏的入口对齐；此前会直接跳到设置。
- 窄屏顶栏的空间切换改为图标按钮，避免与搜索、刷新、收藏图标挤在一起；解耦空间横幅改为窄屏 16px 边距。

## 验证方式

- 231 项自动化测试通过（同一套测试覆盖桌面与移动布局断点）。
- macOS / Android / iOS 三端 Release 构建通过；桌面实机安装。
- 移动端真机仍建议重点验证：本地文件夹权限、iOS 画中画、后台下载、局域网遥控。
