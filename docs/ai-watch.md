# AI 字幕与小映陪看 · 1.6

此功能位于所有平台共用的 Flutter 播放器中，默认关闭。用户在「设置 → AI 字幕与小映陪看」填写自己的 Chat Completions 兼容 API、模型与密钥，再主动开启。它使用用户选择的远程或本机 API，不随应用捆绑大语言模型。

通过「Telegram 本地媒体」入口导入的来源不启用本功能，即使全局 AI 设置已开启，也不会发送该来源的台词、问题或画面；其标题同时从影院 Agent 的模型目录中排除。普通本地文件不自动推断来源。

## 使用

1. 配置完整接口地址、模型名称和 API Key。可选择翻译/解释语言、已有字幕翻译、小映陪看，以及是否允许按需画面分析。
2. 播放视频，点击右上角的陪看头像。打开面板时暂停影片，收起后按原播放状态恢复。
3. 使用内嵌或外挂文字字幕。播放器已有独立字幕菜单，可选择轨道、导入文件和搜索在线字幕，无需开启 AI。AI 仅使用播放器输出的文字台词；图形字幕不会自动 OCR。本机字幕由 libmpv 解码，手工导入上限 64 MiB，在线文字字幕与单个下载缓存上限 2 MiB。
4. AI 翻译显示原文与译文；字幕更新后不会把旧台词的翻译挂到新台词上。自动翻译按最新字幕合并，正常调度间隔至少三秒，只保留一个进行中的请求。
5. 向小映提问台词含义、俚语、文化背景、当前情节或场景细节。问答优先于翻译；每条回答标记提问时间和所用资料。
6. 如需分析视觉细节，先允许画面分析，再勾选「本次问题附带当前画面」。必须使用支持图像输入的模型；每次最多发送一张截图，不连续录屏。

当前角色是名为「小映」的女性文字陪看助手，附轻量头像与对话面板；陪看本身没有语音播报、动态人物模型或语音识别。字幕功能针对已有文字，不对无字幕音频做 ASR，也不对 PGS 等图片字幕做 OCR。开发版另有独立的「语音译配 API · 实验性」，由用户配置的语音服务处理音频，不使用本功能的文字 API；协议、数据与平台范围见根目录 README 的「放映、精彩帧与语音译配」。开启译配会暂停字幕模型请求，后台、跳播、小窗和打开陪看会结束译配，避免两条 AI 流程同时自动运行。

## 数据与资源

- 默认关闭时，不发起 AI 请求、不截取画面、不积累陪看上下文。
- 翻译发送影片名和当前字幕；陪看发送影片名、当前时间、最多 16 段已出现的台词和本次问题。不发送文件路径、NAS/网盘凭据、整部影片、影片简介或未来字幕。
- 只有用户同时允许画面功能、并勾选本次附图时才截图。截图最长边 640px、编码后最多 512 KB；原始图片上限 8 MB。超过 4K 或仍然过大的画面会提示改用台词分析。
- native 播放器截图可能短时分配原分辨率画面，缩小后的输入限制并不等于进程峰值内存限制。解码资源使用完即 dispose，图像不进入问答记录或持久缓存。
- 单片会话最多 16 段台词、48 条译文和 8 次问答，只有一个网络请求和一个截图任务。字幕长度最多 1600 字符，问题最多 500 字符，单次回答最多 4000 字符。
- 收起面板停止未完成的陪看请求；跳播清理时间上下文；切片、应用隐藏/移动端进入后台、关闭功能或主动清理时释放会话缓存。前台恢复后重新按需工作。
- 不将台词、截图与问答写入片库或任务记录。配置 JSON 不含 API Key；密钥复用应用已有凭据桥，iOS/macOS 使用钥匙串，其他平台使用应用受限目录中的凭据文件。
- 网络请求不跟随重定向，35 秒整次超时，响应体上限 128 KB。关闭、取消和配置变更使旧请求失效，旧结果不回填界面。

## 回答的边界

系统提示要求不剧透、基于已提供的信息、区分观察与推测并承认信息不足。单帧分析不等于观看整段视频；模型仍可能误解角色、细节和剧情，应以原片为准。API 费用和远程数据处理由用户选择的服务决定。

## 验证

新增测试覆盖默认关闭、API 密钥隔离、字幕结果对应、缓存边界、跳播与取消、前后台恢复、撤销画面授权、HTTP 重定向、错误回显，以及手机表单/键盘布局与实际图像缩小。

真实商业模型、真实 NAS/网盘影片及各类字幕编码仍需接入用户环境验证；本地测试 API 的固定回答只用于验证数据链路。

1.6.0（7）已通过 94 项自动化测试；macOS 原生播放器已用本机测试 API 验证字幕导入、双语翻译、文字陪看与单帧请求。macOS、iOS ARM64 与 Android Release 均已构建。Android 包已核对版本、INTERNET 权限、APK 签名和 16 KB ZIP 对齐；iOS 与 Android 尚未完成真机运行验证，Windows / Linux 本轮未构建。

Android 预览构建可通过 `ORG_GRADLE_PROJECT_seewowNdkVersion` 指定已经安装的 NDK；未指定时保留 Flutter 默认版本。本次使用 27.1.12297006，避免依赖未完成的本机 NDK 下载。Android 预览包使用工程现有开发签名，不作为商店发布包。
