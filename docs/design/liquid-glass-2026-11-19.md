# Liquid Glass 方向 · 2026-11-19

> 触发人：产品负责人。原话：底部 tab 不符合液态玻璃规范；播放界面布局没有特色，音量频谱与 AB 重复应放在操控界面；液态玻璃动效太少；文件打开/关闭动效一般；显像管、电影院、老电影、杜比、OLED、墨水、动漫等画风要能一键切换并应用。
>
> 本文记录这五项如何落地、落在哪些文件、以及哪些限制是明确承认的。

## 0. 与原复盘的关系

`ui-review-2026-11-17.md` §4 写过「不为了看起来高级加大面积渐变或玻璃拟态」。那条是「不要装饰性玻璃」的执行口径，现在被产品负责人明确覆盖：

- 玻璃只出现在**层级确实存在**的地方（浮起的底栏、播放器控制台、抽屉），不铺在内容区；
- 动效只用于**位置与状态的转换**（选中吸附、页面开合、画风切换），不做常驻循环装饰；
- 默认皮肤是纯平石墨，玻璃观感来自「流光玻璃」皮肤与新的玻璃底栏材质，两者都读过 [SkinSpec]。

## 1. 材质：`lib/design/liquid_glass.dart`

| 组件 | 作用 |
| --- | --- |
| `LiquidGlass` | 背景模糊 + 受光渐变 + 渐变描边 + 顶部高光带 + 外投影；纯平皮肤自动退化为实色面，无模糊开销 |
| `GlassSheen` | 一次性扫光：由 `play` 递增触发，扫完即停，不做常驻 ticker（常驻循环既违背动效纪律，也让 widget 测试永远无法 settle） |
| `PressableLens` | 按下时镜面提亮 + 0.965 压缩，松开回弹；读系统 reduce-motion |
| `GlassPageRoute` | 页面开合：淡入 + 0.972 缩放入场，关闭反向 260ms |

模糊 sigma 来自皮肤 `blur`，透明度来自 `opacity`，纯平皮肤下 `sigma = 0`，直接跳过 `BackdropFilter`。

## 2. 底部导航：`lib/design/liquid_nav.dart`

- 悬浮胶囊，左右各 12、底部让出安全区，不再贴着屏幕边缘。
- 选中态是**同一块玻璃**在座位之间移动：移动过程中横向拉伸（最多 seat×0.18），落位回弹，符合「液体」而不是「高亮条」。
- 五座：放映 / 片库 / Agent / 片源 / 更多；短剧、直播、音乐、片单仍收在「更多」，信息架构未改。
- 每次换座触发一次扫光；reduce-motion 下时长归零。

实测截图（流光玻璃皮肤、390×300 裁切）：`docs/screens/flutter-liquid-nav.png`。选中块的顶部高光带与描边在深底上可辨，未选中图标抬到 `muted 0.88` 保证可读。

## 3. 播放控制台：`lib/playback/player_console.dart` + `player_screen.dart`

- 控制栏换成 `LiquidGlass` 控制台（半径 20），三行结构：**频谱 + 时间码 + AB**、进度条（带 A/B 两个刻度）、传输键。
- 音量频谱 `SpectrumMeter`：读播放器现有 RMS 电平（`AudioLevel`，100ms 一次），按钢琴键包络塑形成条形；起音快、回落慢。**不是 FFT**，界面与文档都不声称是频谱分析。
- AB 循环 `AbLoopControl`：一次点按标 A，再点标 B 并开始循环，第三次重点。已标记时显示 `AB 01:05–01:20`，旁边一个清除键；进度条同步画出 A、B 两条刻度。
- 画风按钮在传输行，点开在同一块玻璃里展开横向画片条，**一次点按即应用**。

## 4. 画风：`lib/playback/video_look.dart`

八种：原色、显像管、电影院、老电影、杜比、OLED、墨水、动漫。

- 每一款 = 一条 4×5 颜色矩阵（`VideoLook.grade()` 生成）+ 可选物理层（扫描线、颗粒、晕影、闪烁、片门晃动、光晕）。
- 覆盖在 `Video` 之上，由 `VideoLookView` 包裹；切换时用 300ms 白光过渡掩盖矩阵跳变。
- 选择立即写入 `PlaybackPreferences.look`，重启后仍在。

**明确的能力边界**（README 的「诚实的边界」同样适用）：

- 这是渲染后的滤镜，不是解码链路的色调映射。杜比与 OLED 在此是「观感档位」，不涉及杜比视界元数据、不做 HDR 解码；
- 颗粒与闪烁需要逐帧重绘，只在选中带物理层的画风时启动；reduce-motion 下静止；
- 片源本身没有的高光细节，画风补不出来。

## 5. 验证

- `test/video_look_test.dart`：八款齐备、id 唯一、矩阵 4×5、原色为单位矩阵、未知回退原色、墨水行权重一致、覆盖强度范围、原色不套 `ColorFiltered`。
- `test/spectrum_ab_test.dart`：频谱零电平全平、高频端衰减、非法电平不出界；AB 的 A→B→重标流程、B 过近抛错、控制台文案与清除按钮。
- `test/liquid_nav_test.dart`：五座渲染、点按回报座位号、重复点当前座不触发、reduce-motion 不报错。
