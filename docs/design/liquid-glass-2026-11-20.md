# Liquid Glass 规范 · 入口 · 标识 · 2026-11-20

> 触发人：产品负责人。原话四条：① 兼容苹果液态玻璃的设计规范；② 每个页面入口的合理性、易用性与创新性；③ 整体提高审美；④ Logo 没有体现「AI 新视频体验」应当让人眼前一亮的意义。
>
> 本文逐条交代：规范怎么落地、落在哪个文件、哪些入口被改、为什么改、标识怎么构成、哪些事明确没做。结论都能指到代码或可复现的渲染产物，不写「感觉更好了」。

## 0. 与上一轮的关系

上一轮（liquid-glass-2026-11-19.md）解决了「有没有玻璃、底栏动效够不够」。这一轮解决**规范符合度**：上一版只有「模糊 + 描边 + 高光带」三层，缺了真实材料的三个关键特征——同心圆角、内阴影边、明暗两种材质。缺一个，玻璃就退化成「半透明卡片」。

## 1. 苹果液态玻璃规范 → 落点对照

苹果在 2025 年给出的 Liquid Glass 不是一种配色，而是一组材料行为。下面每一条都对应到本仓库实现，做不到的写明原因，不含糊。

| # | 规范要求 | 本仓库怎么落地 | 位置 |
| --- | --- | --- | --- |
| 1 | 玻璃是分层材质，不是一个半透明色块：背景模糊 → 色调体 → 外高光边 → 内阴影边 → 接触投影 | 五层固定顺序，缺层即退化。内外描边之间留 `GlassTokens.thickness = 1.4`，这条缝隙就是材料厚度 | `lib/design/liquid_glass.dart` `LiquidGlass` / `_GlassEdge` |
| 2 | 同心圆角：嵌套面板不是各自选圆角，而是「父圆角 − 内缩」 | `GlassTokens.concentric(outer, inset)`，下限 8；`LiquidGlass(concentric: (outer: 28, inset: 6))` 直接算 | 同上；底栏 28 / 选中块 22 |
| 3 | 材质自适应：深底偏暗、浅底偏亮，白描边不能画在白玻璃上 | `GlassTone { auto, dark, light }`，`auto` 从当前皮肤判定；浅色材质换成「白高光 + 深发丝」，投影 alpha 由 .42 降到 .16 | `GlassTokens.resolve`、`LiquidGlass.build` |
| 4 | 折射感：边缘要把背景「弯」一下，而不是只画一条边 | Flutter 不能采样位移做真折射，改用可验证的近似：`refraction` 控制内阴影边与内反射光带强度，制造厚度与弯折方向 | `_GlassEdge` |
| 5 | 交互态：按下有镜面提亮与轻微压缩，且键盘可达 | `PressableLens` 接入 `FocusableActionDetector`：Tab 可聚焦、Enter/Space 激活、焦点环 2px 且不推布局 | `liquid_glass.dart` |
| 6 | 过渡：页面开合是「一片玻璃滑到另一片上」，不是弹窗 | `GlassPageRoute`：淡入 + 0.958 缩放 + 12px 下沉，380ms `Cubic(.16,1,.3,1)`，返回 260ms | 同上 |
| 7 | 动效尊重系统设置 | 时长读 `MediaQuery.disableAnimationsOf`；扫光 `GlassSheen` 一次性，不做常驻循环 | `GlassSheen` / `PressableLens` / `GlassPageRoute` |
| 8 | 降低透明度 / 高对比 | `MediaQuery.highContrastOf` 为真时**不挂** `BackdropFilter`，直接给不透明面；有测试守着 | `LiquidGlass.build`、`test/liquid_glass_spec_test.dart` |
| 9 | 触控目标 ≥ 44 | `GlassTokens.touchTarget = 44`；`GlassButton` 视觉 36、命中 44；`GlassIconButton` 恒 44 | `GlassButton` / `GlassIconButton` |

**明确没做**：真折射（需要采样背景纹理再位移，`BackdropFilter` 不提供）、玻璃之间的融合/粘连动画（iOS 26 的 morph 融合，Flutter 无对应 API）。这两条不写进「已实现」，界面也不暗示。

## 2. 入口改造：逐屏交代

审查方法是从代码证明，不凭感觉。左列是审出来的缺陷，右列是这一轮实际改的。

| 屏 | 审出来的问题 | 这一轮改了什么 |
| --- | --- | --- |
| 全局外壳 | 分区名只在 ≥760px 显示——正好是手机上最需要它的时候没有 | 分区名常显（手机 18 / 桌面 20），手机把搜索框换成 44px 玻璃图标钮，搜索不消失也不挤 |
| 全局外壳 | 第 5 个座位永远写「更多」，四个目的地藏在一个无信息量的词后面 | 座位**记住上次那个分区**，图标与名称随之变化；已站在该分区上时再点才开抽屉。抽屉换成 `GlassSheet`，分「浏览 / 管理」两组 |
| 全局外壳 | 只有 ⌘K，一个快捷键管不了分区 | ⌘1…⌘5 直接站到座位上（macOS 用 ⌘，其它平台 Ctrl），复用同一个 `_navSelect`，第 5 座行为与手点一致 |
| 首页 | 货架卡片只能进详情，起播要「卡片 → 详情 → 播放」三击 | `FilmCard` 增加 `onPlay`：桌面悬停浮出玻璃播放钮，手机常驻（手机没有 hover，需要 hover 的控件在手机上等于不存在）；命中区 44 |
| 首页 | 空推荐只有一句话 | 空态入口沿用上一轮已有的「连接第一个片源 / 载入示例片库」，本轮不再加重复入口 |
| 媒体库 | 筛选到空结果时 action 为空，无路可退 | 空结果给「清除筛选」，一次复位搜索/来源/类型/分类/观看状态/离线筛选 |
| 媒体库 | 网格卡片同样只能进详情 | 与首页共用 `FilmCard.onPlay` |
| 影院 Agent | 输入框只能点按钮提交 | ⌘/Ctrl + Enter 提交；空历史从死胡同变成「先让 Agent 检查片库」一键起步；示例 chip 命中区抬到 48 |
| 片源与订阅 | 无来源时是纯文字 | 该屏已有 8 个磁贴 + 主按钮，本轮不动，避免再造第九个入口 |
| 离线缓存 | 全 App 唯一用系统 AppBar 的页面，像另一个应用；空态没有出路 | 换成玻璃头部（同一枚返回圆钮 + 标题 + 计数），空态给「去片库挑一部」，直接回片库 |
| 影片详情 | 播放/待看/缓存/喜欢四个同权重按钮并列，主次不清 | 一个主按钮，其余收成三枚 44px 玻璃图标钮（选中态用强调色），层级一眼可读 |

跨屏重复入口（审查结论：连接片源 13 处、离线缓存 5 处、AI 配置 5 处）这一轮只把离线缓存的三个调用点收成一个 `_openDownloads()`，其余留到下一轮，理由见 §5。

## 3. 标识：为什么是「玻璃碎片 + 光」

旧图标是白圆角方块 + 黑播放三角——每个播放器都有，且和 AI 没有关系。新标识要同时回答三件事：这是视频、这是玻璃材质、这里有智能。

**构成**（全部由 `lib/design/brand_mark.dart` 画出，一份源码生成所有尺寸）：

1. **轮廓**：播放三角，但左侧是加厚脊线、顶点收成透镜、三个角半径不等（168 / 150 / 214）。等半径会退回成通用播放键；不等半径让 16px 也保留「碎片」而非「按钮」的观感。
2. **材质**：左上到右下递亮的玻璃渐变 + 棱镜色散（冷青到暖粉，低透明度）+ 切割边的湿边高光 + 内阴影倒角 + 接触投影。灰脏的过渡，就是省掉内阴影与湿边的代价。
3. **光**：顶点前方一团无硬边的径向光晕（任何尺寸都不脏）+ 顶点旁的四角星与伴星。星是唯一的非几何形状，也是「这里有智能」的全部理由：光**穿过**画框继续走，而不是停在框里。

**为什么算眼前一亮**：暗底上的高亮玻璃碎片加一颗星，是 29px 拖动栏里唯一还能保留对比度的组合；它不是常见的「紫色渐变 + 播放键」，也不用 AI 生成图（生成图缩到 16px 会糊、边缘不可控）。所有尺寸是矢量重绘，不是缩放。

**资产**：iOS 20–1024（RGB、无 alpha，App Store 会拒绝带 alpha 的图标）、macOS 16–1024（保留 alpha 的圆角卡片）、Android 48–192、`docs/screens/brand-mark-1024.png`，以及应用内 `WowMark` 组件（侧栏 34 单色版、启动页 92 完整版）。生成器 `tool/render_icons_test.dart`：PNG 由本仓库自己编码，不依赖外部图形库。

## 4. 审美：这一轮落下的规则

- **一个按钮形状**：`GlassButton` / `GlassIconButton` 是全仓唯一的次要操作形状，不再各自 `OutlinedButton`。
- **标题即锚点**：顶栏分区名用衬线 display，不再是 12px 灰字。
- **主次分明**：详情页 1 主 + 3 图标，不再四颗同级药丸。
- **玻璃只出现在层级真实存在的地方**：浮起底栏、抽屉、搜索胶囊、卡片播放钮、图标钮；内容区继续平铺。
- **色散是温度不是彩虹**：只在玻璃内部低透明度出现，界面主色仍是单色。

## 5. 明确没做（下一轮第一批）

1. 直播页收藏星、_NoResults 空态、短剧页裸 GestureDetector（缺焦点与键盘激活）——文件内可修，但这轮优先保证「每屏至少一个不死路的空态」与全局导航，避免一次改 11 屏把回归面放大。
2. 详情页与陪看面板的 Esc 返回：全局 Esc 会与播放器内部 Esc 打架，需要先定「谁拥有 Esc」，属交互规范问题。
3. 设置页 5 个 AI tile 合并成一张分组卡、设置项进 ⌘K 调色板：会改信息架构，按流程应与产品确认后再动。
4. 真折射与玻璃融合动画：受 Flutter 能力限制，见 §1 末尾。

## 8. 第三批：状态胶囊、Esc 规则、入口收敛

三条都按「先把数据/规则补上，再做界面」的顺序做；真折射依旧不做。

### 8.1 设置页 AI 分组：先补数据源，再上胶囊

新增 `lib/features/settings_status.dart`：`AiStatusSnapshot.load()` 从**对话框写入的同一批存储**读状态——语音译配（VoiceTranslationConfig）、AI 封面（CoverGenerationConfig）、影片信息补全（TMDB read token）、自定义刮削（CustomScraperRepository）、小映陪看（WatchAiSettings）。每一项都单独 try/catch：某个配置文件坏了，只让那一项显示「未配置」，不许把设置页整页打挂。

界面侧：AI 分组改成有状态的 `_AiSettingsGroup`，五行各带一枚胶囊（已接入 / 未配置，绿色只在已接入时出现），分组标题变成「6 项 · N 项已接入 · 密钥只存本机凭据存储」，并且**每次对话框关闭后重新读取**——胶囊不可能落后于它背后的对话框。

边界（写进代码注释）：影片信息补全只以 TMDB token 为准，其他资料源不逐项判断；胶囊只说「有没有配」，不说「配得对不对」。

### 8.2 Esc 规则：成文，然后统一

规则写进 `lib/design/escape.dart` 与本节：**最内层打开的界面拥有 Esc**。播放器里的面板压过播放器，播放器压过外壳，对话框压过它下面的一切。

- 不做全局绑定。全局 Esc 不知道谁最内层，还会在输入框里抢占「取消编辑」。
- 每个界面用 `EscapeToPop` 包自己：详情、离线缓存、小映面板。
- 焦点不在该界面内时 Esc 不生效——这是刻意的：焦点在哪，Esc 就归谁。

### 8.3 连接片源：定下「两个正门」，先去掉重复的主按钮

规则：**「连接片源」只有两个正门**——桌面顶栏的「连接片源」与片源页本身；空态里的 CTA（首页、媒体库、短剧）只在「什么都没有」时出现，属于情境入口，不算第三个门。

这一批实际做的：

- 片源页里「飞牛 / 群晖 NAS」磁贴与下方实心按钮打开的是同一个 chooser，等于一扇门两把把手。实心按钮降为文字按钮，文案改成「不知道选哪个？查看全部接入方式」——它现在是「帮我选」的兜底，不再和磁贴抢主次。
- 详情页 → 相关影片的第二跳原来丢掉了 `downloads`，「缓存到本地」跳一次就消失，已修。

**没有收敛的**：审查数出来的 13 处里还有若干是「已经连了片源仍然显示添加入口」（片库、短剧、设置）。那属于「按状态隐藏入口」，会改动导航语义，等确认后再动。

### 8.4 验证

- `test/batch3_settings_escape_test.dart`（3 条）：无插件环境下状态快照不抛且全为未配置；设置页 AI 分组出现胶囊；Esc 会关掉最内层的页面。
- 全量 `flutter test` 与 `flutter analyze lib` 的门槛不变：前者全绿、后者 0 错误 0 警告。

## 9. 决定：已连接来源后，添加入口保留

产品负责人定：**保留**。已连接片源后，片库、短剧、设置里的添加入口不隐藏——想加第二个来源（另一台 NAS、另一个账号、一个网盘）是常见动作，隐藏等于把这件事赶回片源页。

由此落下的三处一致化（既然入口都留，就必须长得像一个入口）：

- 首页空态「连接第一个片源」、短剧空态「连接片源」原来是 FilledButton，与片库的 GlassButton 不同形状；统一成 `GlassButton(prominent: true)`。
- 片源页空态原来只有一句「还没有添加媒体来源。选择上方任一入口开始。」——把人送回页面顶部找磁贴。现在给「选择接入方式」按钮，直接开 chooser。
- 「两个正门」规则不变，含义修正为：**门只有两个样式（顶栏 / 页内主按钮），但入口可以出现在任何需要它的地方**；区别在形状与文案一致，不再各画各的。

到此这一轮四条全部有结论：规范落地（§1）、入口（§2/§7/§8）、标识（§3）、审美（§4）；真折射与玻璃融合动画明确不做（§1 末尾）。
