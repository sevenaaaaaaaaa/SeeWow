## 0. 一句话

SeeWow 的视觉方向（Cinema Editorial：衬线标题 + 极暗底 + 单色强调）是成立的，问题在**手感层**：卡片同时堆了四种动效、元数据小到读不出、鼠标之外没有焦点概念、占位海报把标题写了两遍。

## 2. 还没修（按影响排序）

### 2.1 五态只剩「边界」没处理

加载 / 超时 / 错误 / 空 已经在第二批补齐（见 §1.1）。剩下边界一条：`flutter-movies.png` 里出现两张完全相同的 `The Grand Budapest Hotel` 卡片——先按 RM-02 的重叠目录修，再补一条「同 id 不重复渲染」的兜底。

### 2.2 首页 Hero 的进度语义不清

`18% WATCHED` 与 `2 小时 17 分 LEFT` 分列两端，中间那条 1px 线既像分隔线又像进度条。建议合成一条：左侧 18% 进度条（4px，圆角），右侧剩余时间，下方 CTA 保持不动。

### 2.3 侧栏在 1046px 高度下空掉 600px

截图里品牌块 → 5 个入口 → 大片空白 → 页脚。两个可选方向：

1. 加一块「最近观看」竖排 3 张迷你海报（复用 `PosterTile(width: 72, showMeta: false)`）；
2. 窗口高度 < 800px 时收成图标栏（只留 icon + tooltip）。

### 2.4 触控目标偏小

筛选 chip 高 26px、顶栏图标按钮 26–32px。移动端 HIG 建议 44px；桌面上没问题，但同一套代码在手机上就是难按。建议给 `ActionChip` 与 `IconButton` 统一加 `visualDensity` + 最小 40px 命中区。

### 2.5 对比度

`faint #858992` 用在 11px 以下文字时接近 WCAG AA 下限。已把卡片元数据与章节副标题改到 `muted`；还剩播放器时间码、设置页说明文字两处待复核。

## 4. 明确不做

- 不改信息架构（导航层级、页面职责）；
- 不加装饰性动效（Open Design `animation-discipline`：动效只用于空间/状态转换与进度反馈）；
- 不为了「看起来高级」加大面积渐变或玻璃拟态——现有皮肤系统已经能表达这些，交给用户在设置里选。
