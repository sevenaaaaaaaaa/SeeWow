# SeeWow 1.4 — Personal Cinema

本规范描述当前 Flutter 应用。代码事实源为 `skin.dart`、`tokens.dart`、`cinema_widgets.dart` 与 `app.dart`；`tokens.json` 为摘要。1.1 的 HTML preview、theme-lab 和截图作为历史参考保留。

## 产品结构

主导航为「为你放映、媒体库、我的片单、片源与订阅、影院 Agent、直播、设置」。桌面侧栏 210px，平板图标栏 76px，手机底部导航保留放映/片库/Agent/片源/更多；片单和直播从更多进入，亦可通过全局搜索跳转。

首页的重点是今晚要看的影片、继续观看与可执行的 Agent 请求。媒体库承担筛选、排序、批量操作，来源页承担连接与同步，Agent 页承担规划、执行状态和可操作结果。

## 视觉

- 默认「曜黑」：画布 `#090A0B`、导航 `#101113`、面板 `#18191C`，冷白强调色 `#E5EAF2`。系统无衬线。
- 「素白」：画布 `#F4F5F7`、导航 `#EAECF0`、面板 `#FFFFFF`，正文 `#17191E`、强调色 `#243B59`。控件、菜单与弹窗使用浅色主题。
- 「流光玻璃」：深蓝灰底、低饱和环境光、局部磨砂与透光面板。表面裁切后模糊，海报网格不做模糊。系统减少动画时关闭模糊。
- 通过语义颜色统一正文、次级文字、强调、边界和状态。禁止把固定影院绿写入主界面。画面上的内容保持深色遮罩与白色文字。
- 样式与布局尺寸由皮肤参数统一提供：字体、面板圆角、海报圆角、密度、模糊和透明度。
- 换肤立即应用并串行持久化。旧版本预设在首次升级迁移到曜黑；已保存的新格式皮肤继续恢复。
- 工作室草稿独立预览，取消不修改当前主题。JSON / Markdown 导入、design.md 参数本地生成，以及用户模型 AI 生成共用校验器。社区示例明确标注，无在线市场的虚构数据。
- 设计格式与约束见根目录 `skins/README.md`；可编辑模板为 `design.md`。

## 交互

- 所有展示为操作的入口必须有实际行为；不用 Text 模拟搜索框，不展示未接通的播放设置开关。
- 顶部搜索与 ⌘K/Ctrl+K 打开同一个真实命令搜索；可打开匹配条目，或在媒体库查看全部结果。
- 使用 Material 按钮、InkWell 与系统表单实现键盘焦点、按压反馈、工具提示、选中和禁用状态。
- 首页不自动轮播，不重放长入场动画。减少不必要的悬浮变形与指针追踪。
- 窄屏和大字号可增加 Hero/继续观看区域高度。主页面使用惰性列表/SliverGrid，避免为全片库一次创建所有海报。
- 片单保存使用真实条目 ID；断开来源保留原文件。来源失败保留上次片库并持续显示错误，重试成功后清除错误。

## Agent 的状态与承诺

- 必须区分「本地规则」与「AI 模型」，说明本次数据发送的服务和范围。
- 每项任务展示输入、模式、步骤状态、结果、错误和重试；不得将模型或扫描失败显示为成功。
- 模型只能规划白名单工具；引用目录外影片或请求未授权的来源刷新会被拒绝。
- 推荐与搜索结果能打开详情、反馈、加入待看、保存片单。链接候选经用户编辑连接后才导入。
- UI 明确提示网盘需 WebDAV 网关、链接收集不等于全网搜索、体检不等于自动元数据修复。

## 验证

常规字号在 375 / 768 / 1440px 验证首页、媒体库、来源、Agent 和详情；额外验证 375px 的 1.6 倍文字。连接弹窗可滚动，不因键盘或窄屏隐藏提交项。macOS 人工验证全局搜索、Agent 结果保存和重开、播放与返回后的进度刷新。

## 1.3 能力与反馈

- 详情页「匹配影片信息」遵循搜索 → 候选 → 详情预览 → 确认保存。取消不改变媒体库。默认只补缺失图片，用户可以选择替换为 TMDB 图片。
- 电影匹配保留条目 ID 和文件路径；剧集保持来源的分组键，整部剧应用匹配，新扫描集数继承匹配。观看进度、待看与片单关系保留。
- 片源表单使用可扩展的类型选择器，提供 NAS、WebDAV、Jellyfin、Emby、直播订阅。API Key 和用户 ID 有各自明确标签，不把服务器登录显示成网盘原生授权。
- Agent 执行中显示「停止后续步骤」，取消请求后显示等待停止状态；当前来源扫描会完成，后续步骤跳过。取消与失败分别记录，均可重新发起。
- 面板使用 Material 表面，让列表点击和按压反馈实际可见。TMDB 在元数据界面与关于区域显示官方标志和来源声明。

## 1.4 国内来源与音乐

- 服务选择器按用户优先清单排列，支持名称搜索、NAS / 媒体服务器 / 网盘 / 音乐服务器分类。每个服务显示实际接入方式；网盘显式标注网关方式与原生授权待接。
- 来源记录分别保存服务身份、协议和根目录。编辑连接保留来源 ID；填写新地址时要求重新填写凭据，不把旧地址的密钥默默发到新主机。
- 播放器打开前解析 OpenList / File Station / Navidrome 的运行时地址；片库保存稳定引用，不保存临时下载地址、DSM 会话或 Subsonic 认证签名。
- 音乐库单独导航，默认列表视图。Navidrome 曲目不会进入电影推荐；音频播放显示曲名、歌手和专辑，不显示不可用的影片元数据匹配入口。
- 本地、SMB、WebDAV 扫描优先读取已有中文 NFO 资料；与在线 TMDB 手工匹配、服务器自带元数据的来源角色区分清楚。

## 1.6 AI 字幕与小映陪看

- 所有平台共用播放器和配置入口，默认关闭。自行配置 API 与模型，明确发送台词/时间/可选画面的范围和 API 费用。
- 小映采用轻量女性头像与文字面板。打开暂停影片，收起按原播放状态继续，不使用持续动画或加载本地模型。
- 已有文字字幕翻译原文译文同显；PGS 图片字幕和 ASR 不包含在本轮。支持轨道选择及 UTF-8 SRT/VTT 导入。
- 时间点与上下文冻结到每次提问，回答显示时间与输入类型。要求不剧透且承认不确定，界面说明 AI 可能误解。
- 画面授权分为设置允许与单次勾选，最长边 640px，不连续截图。背景与关闭时取消工作，缓存严格有界。

## 用户自带列表与 Telegram 本地目录

- 播放列表使用「读取预览 → 选择下级配置或确认频道 → 导入」。读取预览不写入订阅；编辑地址或局域网读取权限后必须重新预览，取消不导入。
- M3U / TXT / JSON 是数据兼容，不宣称支持完整 TVBox 点播。爬虫和解析插件仅提示不支持，不下载、不执行；无频道的配置不能确认导入。
- Telegram 本地媒体直接选择设备上的已下载目录；不展示账号登录成功、频道同步或云端播放等尚未实现的状态。此来源禁用 AI 处理，重新选择同一目录不能默默取消这一限制。
- 弹窗在 375 / 768 / 1440px 可滚动，手机 1.6 倍字号仍可到达取消和确认按钮；不将原始含令牌 URL 放进失败提示。

## 多语言资料与独立字幕入口

- 资料预览显示原名、所选语言、地区、人员和评分来源。每项评分保留满分尺度和票数，不混合计算或伪装成缺失平台的分数。
- 图片预览后选择，主动选择图片会开启替换选项。标题、年份和语言改变后旧预览失效；确认前不修改片库。
- 电影和剧集使用对应目录；分集可匹配整剧或当前季集，特别篇支持第 0 季。当前集匹配不更名整部剧。
- 任意媒体类型有本地资料编辑入口，可导入 NFO，不将手工补全标成在线刮削。NFO 和服务器资料随扫描更新，人工确认资料保留。
- 字幕菜单不依赖 AI 开关，包含轨道、本地文件、缓存与同目录文件、在线检索。结果显示语言与发行版本，用户主动下载前不消耗下载额度。
- 设置明确凭据、数据发送与来源；商业服务方案不承诺包含在 SeeWow Pro 内。字幕下载不携带账号头访问文件站点，不覆盖用户媒体目录。

## 地区译文与本机批量补译

- 日本、韩国、香港、台湾、俄罗斯、西班牙、阿拉伯语与藏文作为默认地区选项；香港与台湾独立存储。多个地区版本可同时展开，保留资料源实际提供的其他语言，不将回退语言伪装成目标语言。
- 资料卡逐字段标注资料源／本机机译；缺失内容明确留空。保留原始标题与人员姓名，角色和职务译文独立展示，不生成或换算评分。原资料发生变化时显示机译可能过期。
- 阿拉伯语资料文本采用 RTL 与右对齐，控制面板继续使用当前应用语言。藏文字体为随包 Noto Serif Tibetan，行高 1.9；阿拉伯文字体为 Noto Sans Arabic，许可随包展示。
- 单项或最多 20 项采用「采集现有译文／本机补译 → 预览 → 勾选 → 保存」。取消不写入，停止保留已完成的预览；保存前校验条目资料没有并发变化，冲突时整批拒绝覆盖。
- 本机翻译的服务地址与模型单独配置，明确要求离线模型；不附带或下载模型，不回退远程服务。来源的 AI 限制在请求及保存阶段均校验。文字脚本检查不等于语言质量保证，藏文需人工审核。
- 多语言标题、简介及资料源地区别名进入片库与命令搜索。地区目录搜索针对元数据，不表示搜索视频播放源。

## 自定义资料服务与 AI 配图

- 设置中的自定义刮削 API 与图像服务独立配置，密钥使用密码输入并说明空值保留、更换地址重新填写。字段映射为数据路径，不提供脚本执行入口；自定义类型与资料来源明确展示。
- 自定义匹配遵循搜索 → 选择 → 预览 → 确认；修改查询、语言或服务后清空旧预览。仅保存当前条目，检查并发资料变更，保留文件与进度。空结果、错误和取消有真实状态。
- 缺少封面的详情提供 AI 生成入口；描述可编辑，说明发送服务、数据范围与潜在费用。已有封面需要勾选替换，禁止未经用户操作自动生成或扣费。
- AI 图片先预览再保存；库内图片展示 AI 配图标记，详情显示模型与非官方海报说明。标记不改变作品评分、人员或原始标题。限制 AI 的来源不可生成或保存。
- 手机大字号、平板、桌面和横屏的弹窗内容可滚动，取消与保存始终可达；生成请求可停止，保存过程中不显示会误导用户的停止请求按钮。

## 仪式放映与学习播放

- 光盘旋入与 SeeWow 聚光片头使用原创矢量动效，不复制第三方片头、商标或配乐。约 2.1 秒，始终可跳过；系统减少动态效果、直播和音频直接进入内容。预加载不播放正片，过场结束后才开始播放。
- 桌面全屏保留整个播放器与自定义工具，不创建只有视频的空控制路由。暂停时保留控制栏；小窗只显示播放、恢复与关闭等必要控件，关闭恢复原窗口状态。
- AB 显示 A／B 时间，B 至少晚于 A 0.5 秒；直播与不可定位媒体不提供无效循环。手动跳播和开启译配清除循环，快捷键和菜单行为一致。
- 精彩帧先暂停、预览和编辑备注，再确认本机保存；取消不保存。图库支持缩放、本片定位与确认移除，不自动上传到模型或改动原片。
- 电平来自实际 PCM 样本，不使用随机波形。原片采样不修改主声道，译音复用已有样本；不可用显示缺失状态，后台与隐藏控件不继续采样。
- 语音译配明确标记实验性、目标语言、发送服务、音色声明、许可与费用；一段约 6 秒，有界预取，缓冲时显示等候，不伪装成无延迟。停止、失败、切片、后台与小窗恢复原声；不将服务的音色声明当成已验证事实。
