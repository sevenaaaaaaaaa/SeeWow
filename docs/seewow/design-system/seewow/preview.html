Cinema Editorial

SeeWow 的视觉语言：一块幕布、一本电影刊物、一组克制的运动。本页由 apps/seewow/lib/design 与现有界面反推，只描述 SeeWow——不包含 Awake 的任何规则。

00

原则

Principles
01 / Stage

影院先于界面

屏幕是幕布：黑场、颗粒、暗角、投影框。UI 只在需要时浮出来，不抢画面。

02 / Editorial

编辑排版

衬线大标题、等宽元数据、零填充序号、发丝线。像电影刊物，不像后台面板。

03 / Artwork

海报是主角

颜色从海报来，版式给海报让路；文字块永远停留在墨色里。

04 / Focus

一屏一焦点

首页只有一个 Hero；页面只有一个一级标题；强调色只落在当前那一处。

05 / Motion

克制而有编排

入场 620ms、错峰 ≤320ms；悬浮只允许 -8px、1.035 倍、轻微倾斜三种。

06 / Bilingual

双语是版式

中文承担语义，英文等宽大写承担节奏；两者同时出现时，英文不翻译中文。

01

色彩

Color

四套暗色配色（古铜 / 暖墨 / 墨蓝 / 石墨），每套七个色位；发丝线取当前 text 的 10%，不是固定白。强调色独立于配色，四选一；只有「紫」保留 accent2 = #54C8FF，其余强调色的 accent2 等于自身。下列为默认预设，点击色块可复制。

01.2

白色透明度阶梯

Alpha ladder

规范口径：文字、描边、填充收敛到七档 a92 / a72 / a55 / a38 / a26 / a14 / a07。现状代码仍有 0.30 / 0.45 / 0.58 / 0.66 等中间值，新增代码只从七档取。

02

字体

Typography

默认标题用 Source Serif 4，中文回退宋体；1.1.0 起标题族可切四组声音（宋衬线 / 人文衬线 Palatino / 无衬线 / 几何 Avenir Next），字号与字距不变。标签与元数据固定 JetBrains Mono，正文用系统无衬线。中文标题只用 w400 / w500。

09

规则

Checklist
交付前自检
  • 新颜色只进 skin.dart 的配色/强调色 map，并同步 tokens.json。
  • 四套配色 × 四种强调色至少各看一遍，重点检查琥珀与冷青。
  • 发丝线用 WowColors.line，不用白色 alpha 画。
  • Logo 用 legacyLogo 判断，只有紫色走紫→青渐变。
  • 主按钮仍是白底黑字；强调色不做大面积背景。
  • 外观芯片圆角 8、恢复默认 7；筛选芯片仍是 14。
  • 背景四种都看，flat 无暗角；海报 neutral 无彩色。
  • 中文标题 w400 / w500；动效 ≤620ms，换肤无过渡。
反模式
  • 浅色模式、跟随系统亮色。
  • 页面里写死 Color(0xFF8B7BFF) 一类色值。
  • 非紫色还画紫→青渐变，或给 accent2 硬塞第二色。
  • 用白色 alpha 画发丝线；大面积 accent 填充。
  • 外观芯片用 14/26 圆角；普通卡片投影/玻璃模糊。
  • 预设改变布局、字号、圆角或动效；换肤加淡入淡出。
  • emoji 当图标；第二套图标库；正文衬线。
  • 滚动触发入场重播、弹跳、视差。
