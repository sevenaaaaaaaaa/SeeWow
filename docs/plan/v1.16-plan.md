## 二、两个需要你知道的技术边界（会影响方案）

**1. 桌面上没有「晃一晃」的硬件。**
手机能晃一晃，是因为有加速度计。macOS / Windows 的电脑没有这个传感器，操作系统也不会把「桌子震了一下」告诉应用。所以这条只能这样落地：

- iPhone / iPad / Android：真·摇一摇（重力感应，需要引入 `sensors_plus` 依赖）；
- 电脑：改成「窗口晃一晃」——你一秒钟内左右快速拖动窗口两个来回，就当作摇一摇。这个用现有 `window_manager` 就能做，不引入新依赖；
- 两条都遵守你的前提：**只有没有点击、没有在播放的时候才响应**，避免看电影时误触刷新。

如果你更想要电脑上按快捷键（比如 `⌘R`）刷新，告诉我，我把「窗口晃动」换掉或并存。

**2. macOS 上没有真正的系统画中画可接。**
系统画中画要求视频走 AVKit 的播放层，而 SeeWow 的画面是 libmpv 渲染后交给 Flutter 的，AVKit 接不进去。所以桌面端的正确目标是「真悬浮窗」：无边框、始终置顶、可拖动缩放、切到别的 App 也看得见、播放不中断。这跟系统画中画在体验上是一回事，只是不坐在系统的画中画容器里。手机端本来就是系统画中画，这一版做真机复核与失败原因修复。
