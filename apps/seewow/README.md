# SeeWow (Flutter app)

The Flutter implementation of SeeWow — one codebase for macOS, Windows, Linux,
iPadOS and Android tablets.

- Product overview, design language, architecture and build notes: [../../README.md](../../README.md)
- Run locally: `flutter pub get && flutter build macos` (macOS needs `brew install mpv` for the libmpv framework)
- Tests: `flutter test`
